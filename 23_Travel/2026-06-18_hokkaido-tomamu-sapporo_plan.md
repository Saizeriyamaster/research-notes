**乗馬ゆっくり + すすきのでお酒**
作成日: 2026-06-18

## ルート全体図

```
羽田 ✈️ → 新千歳 → [特急2h] → トマム(1泊) → [特急2h] → 札幌(1泊) → [快速40min] → 新千歳 ✈️ → 羽田
```

## 旅のポイント

1. **Day 2 が乗馬の日**。早朝に雲海を見て、午前ゆっくり過ごしてから午後乗馬。夕方に余裕をもって出発すれば、トマムをしっかり楽しんだ上で札幌に着ける。

2. **特急は1日3本しかない**。トマム→札幌の夕方の便を先に確認してから、当日のスケジュールを逆算で組むこと。

3. **札幌のお酒はすすきの一択**。日本最大級の繁華街。北海道グルメ（ジンギスカン・海鮮・スープカレー）とお酒を深夜まで楽しめる。
