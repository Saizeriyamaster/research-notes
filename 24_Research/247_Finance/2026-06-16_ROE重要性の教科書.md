# ROEが重要である理由：投資家のための教科書

---

## 1. ROEとは何か

**ROE（Return on Equity）＝ 自己資本利益率**

$$
\text{ROE} = \frac{\text{当期純利益}}{\text{自己資本}} \times 100
$$

「株主が出したお金（自己資本）に対して、会社がどれだけ利益を生み出したか」を示す指標。

### 構成要素の整理

| 用語 | 意味 |
|------|------|
| 自己資本 | 株主が出した資本 ＋ 内部留保（過去の利益の積み上げ） |
| 当期純利益 | 最終的な税引後利益 |
| 総資産 | 自己資本 ＋ 負債（借入金など） |

---

## 2. 同じ営業利益でも ROE は変わる：自己資本比率20% vs 50%

### 前提条件
- 総資産：1,000億円
- 営業利益：100億円
- 借入金利：2%
- 税率：30%

### ケース比較

|  | 自己資本比率 **50%** | 自己資本比率 **20%** |
|--|---------------------|---------------------|
| 自己資本 | 500億円 | 200億円 |
| 負債 | 500億円 | 800億円 |
| 営業利益 | 100億円 | 100億円 |
| 利息（負債 × 2%） | −10億円 | −16億円 |
| 税引前利益 | 90億円 | 84億円 |
| 税引後純利益（税率30%） | **63億円** | **58.8億円** |
| **ROE** | **12.6%** | **29.4%** |

### 解釈

純利益の絶対額は自己資本比率50%の方がわずかに多い（63億 > 58.8億）。  
しかし株主の立場では、**自分が出したお金（200億）に対して58.8億稼いでくれる会社（ROE 29.4%）の方が、500億出して63億稼いでくれる会社（ROE 12.6%）より効率が高い。**

> 株主は「同じ1円を出すなら、より多く稼いでくれる会社」を好む。  
> レバレッジ（負債）を使うことで、少ない自己資本で同等の利益を生み出せる。

---

## 3. なぜ ROE 8% が一つの基準なのか

**インデックスファンドの長期期待利回りはおよそ 8%。**

```
S&P500の過去平均リターン（配当込み）：約10%
インフレ調整後の実質リターン：約7〜8%
```

株式投資（特定企業の個別株）は、インデックスファンドよりリスクが高い。

- インデックス：数千社に分散 → 1社倒産しても影響小
- 個別株：1社に集中投資 → 倒産すれば全損リスク

**より高いリスクを取るのだから、インデックスを上回るリターンを要求するのは当然。**

$$
\text{個別株への投資基準} = \text{インデックス利回り（8\%）以上のROE}
$$

> ROE 8%未満の会社に投資するくらいなら、インデックスファンドを買った方がリスクに見合う。  
> 機関投資家（年金・生命保険など）もこの基準で投資先を判断する。

## 4. PBR = ROE × PER：株価と ROE の関係

### 各指標の定義

| 指標 | 計算式 | 意味 |
|------|--------|------|
| **PBR**（株価純資産倍率） | 株価 ÷ 1株当たり純資産 | 純資産に対して株価が何倍か |
| **PER**（株価収益率） | 株価 ÷ 1株当たり利益 | 利益に対して株価が何倍か |
| **ROE**（自己資本利益率） | 1株当たり利益 ÷ 1株当たり純資産 | 純資産から利益をどれだけ生んでいるか |

### 数式による証明

$$
\text{PBR} = \frac{\text{株価}}{\text{1株当たり純資産}} = \frac{\text{株価}}{\text{1株当たり利益}} \times \frac{\text{1株当たり利益}}{\text{1株当たり純資産}} = \text{PER} \times \text{ROE}
$$

### 何を意味するか

PBR 1倍 ＝ 「株価 ＝ 解散価値」。資産をそのまま清算したのと同じ価値にしか評価されていない。  
市場は「PBR > 1」、つまり将来の稼ぐ力（ROE）に期待してプレミアムを付ける。

**ROEが高い会社 → PBRが高くなる → 株価が上がる**

---

## 5. 企業がコントロールできるのはROEだけ

株価（Price）は市場が決めるもので、企業自身はコントロールできない。  
しかし PBR = PER × ROE の構造から考えると：

```
PER  → 市場の期待・金利環境・マクロ要因 → 企業がコントロール困難
ROE  → 経営の効率性・財務戦略           → 企業がコントロール可能
```

**企業経営者が集中すべきは ROE の最大化。**

ROEを上げる手段は主に3つ：

1. **純利益を増やす**：売上増加・コスト削減・利益率改善
2. **自己資本を圧縮する**：自社株買い・配当による資本還元
3. **負債（レバレッジ）を活用する**：借入で総資産を拡大し利益を稼ぐ

---

## 6. ROAとの違い：似て非なる指標

**ROA（Return on Assets）＝ 総資産利益率**

$$
\text{ROA} = \frac{\text{当期純利益}}{\text{総資産}} \times 100
$$

### ROE vs ROA

| 比較軸 | ROE | ROA |
|--------|-----|-----|
| 分母 | 自己資本（株主資本） | 総資産（自己資本＋負債） |
| 視点 | **株主視点**：出資に対するリターン | **経営全体視点**：資産全体の効率 |
| レバレッジの影響 | 受ける（負債が多いほど高くなる） | 受けにくい |
| 用途 | 株主価値の評価 | 事業の本質的な収益力の評価 |

### デュポン分析で両者をつなぐ

$$
\text{ROE} = \text{ROA} \times \text{財務レバレッジ}
$$

$$
\text{ROE} = \underbrace{\frac{\text{純利益}}{\text{売上高}}}_{\text{利益率}} \times \underbrace{\frac{\text{売上高}}{\text{総資産}}}_{\text{資産回転率}} \times \underbrace{\frac{\text{総資産}}{\text{自己資本}}}_{\text{財務レバレッジ}}
$$

ROAは高いのにROEが低い企業 → 負債を使わず自己資本が厚すぎる（資本効率の無駄）  
ROAは低いのにROEが高い企業 → 借入で水増しされている（実態は要注意）

## 7. バランス感覚：レバレッジは諸刃の剣

### レバレッジのメリット

- 少ない自己資本で大きな利益 → ROE向上
- 低金利時代は借入コストが低く、利益のほとんどが株主に帰属

### レバレッジのリスク

```
好景気：  利益100億 - 利息10億 = 株主90億  ← 問題なし
不景気：  利益 10億 - 利息10億 = 株主 0億  ← 破綻寸前
```

**負債には返済義務がある。売上が落ちても利息は払い続けなければならない。**

- 自己資本比率が低すぎる → 不況時に一気にキャッシュフロー危機
- 自己資本比率が高すぎる → 資本効率が悪く、ROEが低迷

> 理想は「事業の安定性・成長性」と「財務レバレッジ」のバランス。  
> 安定したキャッシュフローが見込める事業ほど、レバレッジを効かせやすい。

## 8. ケーススタディ：コメダ珈琲が示すROEの本質

### 一般的な飲食チェーン（直営モデル）

サイゼリヤ・マクドナルドの直営店などは、会社が自ら店舗に投資する。

```
【直営モデル】
会社の自己資本 → 店舗・厨房設備・内装・土地 → 利益
```

店舗を増やすほど自己資本（または負債）が膨らむ → ROEが上がりにくい。

### コメダ珈琲（フランチャイズモデル）

コメダは店舗への直接投資をほぼしない。フランチャイジー（加盟店オーナー）が資産を持つ。

```
【フランチャイズモデル】
加盟店オーナーの資本 → 店舗・設備・内装
コメダの自己資本    → ブランド・レシピ・システム → ロイヤリティ収入
```

**コメダのバランスシートには店舗資産がほとんど載らない。**

| 比較 | 直営チェーン | コメダ（FC） |
|------|-------------|-------------|
| 総資産 | 大きい | 小さい |
| 自己資本 | 大きい | 小さい |
| 利益源 | 店舗利益 | ロイヤリティ |
| ROE | 低〜中 | **高い** |

> コメダは「土地も建物も持たずに稼ぐ」ビジネスモデル。  
> 自己資本の分母が小さいため、ROEが構造的に高くなる。

同じ飲食業でも、すかいらーくやサイゼリヤのような大規模直営チェーンは店舗を自社で抱えるため総資産が膨大になり、ROEは構造的に上がりにくい。一方でコメダのようなFC比率の高い業態は、同じ売上規模でも自己資本が少なくて済むため、ROEで大きく差がつく。

この「資産を持たずに稼ぐ」構造は他業種にも共通する。「ファブレス（工場を持たない製造業）」や「プラットフォームビジネス」も同じ理屈で、Apple・Microsoft・Googleがなぜ高ROEかも説明できる。

## まとめ

| ポイント | 要点 |
|----------|------|
| ROEとは | 株主資本に対する利益率。株主視点の最重要指標 |
| 基準値 | 8%（インデックスファンドの期待リターン）を超えること |
| PBR公式 | PBR = ROE × PER。ROEが株価評価に直結する |
| 企業の選択 | 株価はコントロール不可。ROEをコントロールせよ |
| ROAとの違い | ROAは資産全体、ROEは株主資本の効率 |
| レバレッジ | 上げすぎると不景気に脆弱。適切なバランスが鍵 |
| コメダの示唆 | 資産を持たないビジネスモデルが構造的にROEを高くする |

> **ROEは「経営の通信簿」であり「株主への約束」である。**
