# 古河電工の株価3倍と、データセンター投資シグナルの読み方

作成日: 2026-04-10

---

## TL;DR

古河電工（5801）は「光ファイバーケーブルの世界シェア10%を持つ老舗電線メーカー」が、AIデータセンター建設ラッシュで需要爆発した典型例。株価が動く前に、大手テック企業のCAPEX（設備投資）計画→関連産業の受注増→業績上方修正という流れがある。このチェーンを追えば、次の波及先も見える。

## 光ファイバーとは
光ファイバーとは、離れた場所に**「光」を信号として伝えて情報を送るための伝送路（ケーブル）**のことです。

従来の銅線（メタルケーブル）が電気信号を使うのに対し、光ファイバーは光の点滅を利用するため、圧倒的に速く、大量のデータを遠くまで運ぶことができます。

現代のインターネット社会において、光ファイバーが欠かせない理由は主に3つあります。

1. **圧倒的な通信速度**: 1秒間に送れるデータ量が非常に多く、高画質動画や大容量ファイルも瞬時に送受信できます。
    
2. **長距離伝送に強い**: 電気信号に比べて信号の劣化（減衰）が極めて少なく、数キロ先までブースターなしで信号を届けられます。
    
3. **ノイズに強い**: 素材がガラス（絶縁体）であるため、近くにある電線や雷などの電磁ノイズの影響を全く受けません。

## 1. 古河電工の株価がなぜ3倍になったか

### 直接的トリガー：光ファイバー需要の爆発

| 要因 | 詳細 |
|------|------|
| **AIデータセンター建設ラッシュ** | Microsoft（日本4,400億円）、AWS（2.2兆円）、Google（1,000億円）が日本国内DCに大型投資 |
| **光ファイバーの需要急増** | DC内高速通信に不可欠。世界DC容量は2030年まで年33%成長（McKinsey） |
| **MTフェルール（光コネクタ）** | 古河電工が強みを持つ光接続部品の需要急増 |
| **光部門の黒字化** | 長年赤字だった光部品事業がついに黒字転換 → これが株価急騰の本質的トリガー |

### 業績数字の変化

```
2025年3月期：
  営業利益 前年比 +4.2倍
  純利益   前年比 +5.1倍

2026年3月期予想（上方修正後）：
  営業利益 +19.1%
  純利益   +61.9%
```

### 株価急騰のタイムライン

- **2024年11月**: 電線株急伸、光ファイバー期待から古河・フジクラが1週間で6割高
- **2026年2月**: ゴールドマン・サックスが「利益成長が変曲点」レポートを発行 → 3日で6割高
- **2026年3月**: 株価最高値 34,040円（年初来で3倍超）

### なぜ「急騰」だったか

変曲点（インフレクションポイント）の特徴：
1. **赤字部門の黒字化** = 構造変化のシグナル
2. **増産投資の決断** = 需要への自信（製造能力を2023年度比2倍に）
3. **大手証券のレポート** = 機関投資家マネーが流入し始める

## 2. どこでシグナルをキャッチするか

### シグナルの流れ（川上から川下）

```
[川上シグナル]
大手テック企業のCAPEX計画
    ↓
[中流シグナル]
業界メディアで「〇〇向け需要増」記事
    ↓
[業績シグナル]
部品メーカーの受注増・上方修正
    ↓
[株価シグナル]
アナリストが「変曲点」と言い始める
    ↓ ← ここで一般投資家が気づく（遅い）
[急騰]
```

### 見るべき情報源

| 情報源 | チェックする内容 |
|--------|----------------|
| **大手テック企業の決算IR** | CAPEX（設備投資額）の増減。前年比30%超増ならインフラ需要爆発のサイン |
| **日経電子版 / 日経ヴェリタス** | 産業チェーンを追った深掘り記事 |
| **株探（kabutan.jp）** | 業績上方修正ニュース、テーマ別銘柄一覧 |
| **会社の決算説明会資料** | 増産計画・設備投資額・部門別の黒字化情報 |
| **証券会社レポート** | 「変曲点」「ターニングポイント」という言葉が出たら動き始めるシグナル |

### 注目すべきシグナルの種類

- **長年赤字だった事業の黒字化** → 構造変化、最大のシグナル
- **増産投資発表** → 需要に対する経営陣の自信
- **大口受注・長期契約の報道** → 安定的な収益増の予兆
- **業界全体の設備投資計画** → 自分だけ調べるより業界全体を見る

## 3. 株価とニュースをどう繋げるか：業界別の注目ニュース

### 業界によって「効くニュース」は違う

| 業界 | 最重要ニュース | 二次的シグナル |
|------|--------------|--------------|
| **電線・素材（古河電工等）** | 大口顧客（テック企業）のCAPEX計画 | 銅価格、増産計画、工場稼働率 |
| **半導体** | TSMCの生産計画、スマホ出荷台数 | 在庫サイクル（ダウンサイクル脱出）、輸出規制 |
| **電力・重電** | DC建設計画、電力需要予測、系統連系申請 | 政策（省エネ規制、再エネ目標） |
| **建設・不動産** | 大型DC用地取得ニュース | ゼネコン受注、土地価格 |
| **電池・蓄電** | EV販売台数、再エネ普及計画 | 原材料価格（リチウム等）、技術革新 |
| **冷却・空調** | DCの消費電力増大、液冷採用率 | 省エネ規制の強化 |

### 「チェーン思考」の実践

古河電工を例に：
```
「GoogleがDCに100億ドル投資」ニュース
    → DCに光ファイバーが必要
    → 光ファイバーメーカーは？ → 古河電工、フジクラ、住友電工
    → 光ファイバーに銅が要る → 電解銅箔は？ → 三井金属
    → DCには冷却が要る → 冷却装置は？ → 山洋電気、荏原製作所
    → DCには変圧器・電源が要る → 重電メーカーは？ → 富士電機、三菱電機
```

## 4. データセンター周辺で伸びそうな産業

### 直接受益（第一波）

| 企業/分野 | 理由 |
|-----------|------|
| **古河電工・フジクラ・住友電工** | 光ファイバーケーブル、電線の直接需要 |
| **TDK（6762）** | HDD用ヘッド・サスペンション（ニアラインHDD需要急増）、小型二次電池 |
| **三井金属** | 電解銅箔（世界シェア95%超）。サーバー・ルーター全般に使用 |
| **メイコー** | AIサーバー向けプリント基板（マザーボード用） |

### 電力インフラ受益（第二波）

| 企業/分野 | 理由 |
|-----------|------|
| **富士電機** | コンテナ型DC、UPS（無停電電源装置）、変圧器、開閉器 |
| **三菱電機** | 高機能変圧器、電力制御 |
| **日立エナジー** | 高圧直流送電、スマートグリッド |
| **山洋電気** | 冷却ファン、UPS（サーバーメーカーへの採用実績豊富） |
| **荏原製作所** | 液冷・水冷システム（DCの消費電力の30-40%が冷却） |

### 再生可能エネルギー（第三波）

- Google・Apple等がRE100目標（電力100%再エネ化）を掲げており、DCが再エネ需要を引っ張る
- 再エネ電力を送配電する**電線・変圧器メーカー**（住友電工、フジクラ）も恩恵
- **蓄電池**: TDKの小型二次電池、DC用UPSの大型化

### 思わぬ波及効果（意外な恩恵）

| 分野 | 波及の理由 |
|------|-----------|
| **建設・ゼネコン** | DC建設ラッシュ（大林組、鹿島等） |
| **総合商社** | DC開発プロジェクトへの参画（三井物産、住友商事） |
| **液体窒素・冷却水** | 液冷DC普及で冷却材需要増 |
| **土地・不動産** | DC適地（電力インフラ近傍の工業地）の地価上昇 |
| **セキュリティ** | DC物理セキュリティ・サイバーセキュリティ需要 |
| **通信キャリア** | DC間を繋ぐ大容量通信インフラ需要 |

## 投資シグナルを掴む実践フレームワーク

```
Step 1: マクロ動向を掴む
  「生成AI普及 → DC需要爆発」「EV普及 → 電池需要増」
  → このトレンドで誰が儲かるか？

Step 2: バリューチェーンを全部書く
  DCが増える → 電力が必要 → 変圧器が必要 → 変圧器の銅巻線が必要
  → 見えていない部品・材料・製造装置まで掘る

Step 3: 変曲点のシグナルを探す
  ・長年赤字だった部門の黒字化
  ・増産投資の決断（CapEx急増）
  ・大手証券の「買い」転換レポート

Step 4: 割安度をチェック
  PER・PSR・時価総額と業績成長率のギャップ
  「まだ気づかれていない段階」かどうか

Step 5: 自分の強みを活かす
  知っている業界のチェーンは深く追える
  IT系なら半導体→電子部品→素材を追う
  製造業知識があれば重電→素材→加工機械を追う
```

## ユーザーの疑問に直接答えると

**Q. データセンターの話は年始より前からあったはず？**

→ **その通り。** ChatGPT公開（2022年11月）が転換点で、日本のデータセンター投資は2023年から明確に加速（前年比+16.4%、約3,222億円 → 2024年は約5,000億円）。フジクラはその流れに乗って2023〜2024年に先行して急騰していた。

---

**Q. なぜフジクラが先に上がり、古河電工が「追いついた」構図になったのか？**

フジクラは2020年から光事業に経営資源を集中する構造改革を先行して実施し、業績改善が先に「可視化」されていた。市場が最初に反応したのはそのため。

古河電工が遅れた理由：

- 多角化企業（電線・電材・電装品・電子部品）で利益率が低く、「データセンターの恩恵を最も受ける企業」として最初に評価されなかった
- 構造改革がフジクラより後手だった

古河電工が2026年に爆発した理由：

- **2026年2月の決算が「業績変曲点」として認識された**（経常利益25%上方修正＋増配が決定的なシグナル）
- フジクラは既に628%上昇しており「割高感」があった → **フジクラから古河電工への資金ローテーション**（日経記事の見出し「買い遅れの恐怖」そのもの）
- 白山の子会社化（2025年1月完了）でデータセンター向け部品ラインが強化され、業績への織り込みが始まった
- ゴールドマンサックスのカバレッジ開始・格上げが外資系機関投資家の参入を促した

## 古河電工だけの固有の強み（フジクラにはない）

1. **ITLA（光通信レーザー制御回路）で世界シェア50%以上**  
    　 データセンターの光通信心臓部に当たる部品。フジクラは保有していない。
    
2. **ローラブルリボン技術（独自）**  
    　 ミカンネット状の点接続で光ファイバーを高密度収納できる独自ケーブル構造。
    
3. **白山買収によるMTフェルール事業**  
    　 MTフェルール（世界2位シェア）の内製化 + NTTのIOWN（次世代光通信基盤）プロジェクトへの参画権。IOWNは2024〜2025年に注目度が高まっており、将来の国内大型需要が期待される。
    
4. **光ファイバーケーブル製造能力を2023年度比2倍に増強中**  
    　 供給制約が解消された段階での業績加速期待。

## 一言でまとめると

「データセンター特需」はフジクラが先に取りに行き、市場も先に織り込んだ。古河電工は構造改革の遅れと多角化の重さで「出遅れ株」だったが、白山買収でデータセンター部品事業を強化し、2026年2月の決算でその成果が数字として現れた瞬間に、「フジクラを買いそびれた資金」が一気に流入した。3倍というよりは今は3ヶ月で4倍超まで来ている。
