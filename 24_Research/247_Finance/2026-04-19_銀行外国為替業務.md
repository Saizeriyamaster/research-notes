# 銀行の外国為替業務 — 体系的解説

---

## 1. 外国為替業務とは何か

銀行の外為業務は大きく **3層**に分かれる。

| 層 | 内容 | 収益源 |
|---|---|---|
| **顧客取引（Commercial FX）** | 輸出入企業・個人の送金・両替を仲介 | スプレッド（売値−買値の差） |
| **プロップ取引（Prop FX）** | 銀行自身のポジション運用 | キャピタルゲイン |
| **ALM・ヘッジ** | 保有資産の通貨リスクを管理 | リスク削減による損失回避 |

実務上の主な業務:

- **スポット取引** — 2営業日後に決済する通貨の売買
- **フォワード（先物予約）** — 将来の為替レートを今日決める。輸出企業が「3ヶ月後に1ドル=150円で売る」と予約するもの
- **スワップ** — 異通貨の資金を一定期間交換する。ドル調達コストの管理に使う
- **オプション** — 為替レートが特定水準を超えたときだけ権利行使できるデリバティブ
- **送金・決済** — SWIFTネットワーク経由の国際送金処理

## 2. 為替とは何か・どう決まるのか

**為替レート**とは「ある通貨1単位で他通貨をいくら買えるか」という価格。

### 決定の理論体系

```
短期（分〜日）    →  需給・市場心理・フロー
中期（週〜月）    →  金利差・マクロ指標
長期（年〜）      →  購買力平価（PPP）・経常収支
```

**①購買力平価（PPP）**
同じモノは世界中で同じ価格になるはず、という理論。
ビッグマックが日本450円・米国5ドルなら、理論的には1ドル=90円。現実との乖離が長期トレンドを引き戻す力になる。

**②金利平価（UIP/CIP）**
高金利通貨は将来的に減価する（そうでないと無リスク裁定が生じる）。
```
期待為替変化率 ≈ 国内金利 − 外国金利
```
日米金利差が開くと円安方向に圧力。2022〜2024年の円安はこの構造。

**③国際収支**
経常収支黒字（輸出＞輸入）は自国通貨買い需要を生む → 通貨高。
資本収支の移動（対外投資・FDI）は短期に大きな影響。

**④市場センチメント・フロー**
- 機関投資家・ヘッジファンドのポジション
- リスクオン/オフ（有事のドル買い・円買い）
- アルゴ・HFTによるフィードバックループ

## 3. 外為業務における主な変数

### A. マーケット変数

| 変数 | 説明 | 影響方向 |
|---|---|---|
| **スポットレート** | 現在の市場レート | 全業務の基点 |
| **金利差（スワップポイント）** | 2通貨間の政策金利・市場金利差 | フォワードレート・スワップ収益に直結 |
| **ボラティリティ（IV）** | 将来の変動率予測 | オプション価格・ヘッジコストに直結 |
| **クレジットスプレッド** | 国・銀行の信用リスク | CDS・カントリーリスクに影響 |
| **流動性（Bid-Ask Spread）** | 市場の厚み | 取引コストに直接影響 |

### B. オペレーショナル変数

| 変数 | 説明 |
|---|---|
| **バランスシート制約（RWA）** | 自己資本規制（バーゼルIII）でポジション上限が制約される |
| **決済リスク（ヘルシュタットリスク）** | 時差があると片方だけ決済されるリスク。CLS銀行で軽減 |
| **カウンターパーティリスク** | 取引相手のデフォルトリスク |
| **ファンディングコスト** | ドル調達コスト（XCCYベーシス）。2020年コロナ時に急騰 |

### C. マクロ変数

- GDP成長率、CPI、雇用統計（特に米NFP）
- 財政収支・国債残高
- 地政学リスク

## 4. 関税（Tariffs）の影響

関税は **貿易フロー → 経常収支 → 為替** という経路で作用するが、現代では**資本フロー**の逆方向効果も大きい。

### 直接経路：貿易収支

```
輸入関税引き上げ
→ 輸入減少
→ 外貨需要減少（ドル買い↓）
→ 自国通貨高圧力
```

理論的には「関税→貿易赤字縮小→ドル安」なのに、実際の2025年トランプ関税時は**逆にドル安が進行した**。なぜか？

### 逆説的経路：資本フロー

```
高関税→景気悪化懸念
→ 米国資産の魅力低下
→ 外国人投資家の米国債・株売り
→ ドル売り圧力（ドル安）
```

さらに「**米国の政策の予測不可能性**」によるドル信頼の毀損という構造的問題も加わる。

### 銀行業務への具体的影響

| 影響 | 内容 |
|---|---|
| **ヘッジ需要増加** | 輸出入企業がフォワード契約を増やす → 銀行収益増 |
| **ボラティリティ上昇** | オプション取引活性化。プロップ収益は増減両面 |
| **貿易金融の収縮** | LC（信用状）・貿易融資の需要が変化 |
| **サプライチェーン再編** | 決済通貨・送金先が変わる → インフラ投資必要 |

## 5. ステーブルコインによる影響

ステーブルコインは**銀行の外為業務の中間層を消失させる**可能性がある。

### 現在の外為送金の構造（コルレス銀行モデル）

```
送金者 → A銀行 → コルレス銀行B（NY）→ コルレス銀行C → 受取銀行 → 受取人
　　　　　　　　　　3〜5日、手数料多段階
```

### ステーブルコインによる代替

```
送金者 → USDCなどに変換 → ブロックチェーン転送（秒〜分）→ 受取人が現地通貨に変換
```

### 銀行への影響

| 影響 | 内容 |
|---|---|
| **国際送金手数料の消失** | 世界の送金手数料市場は年間約50兆円規模。これが代替される |
| **コルレス関係の希薄化** | 特に新興国向けのde-risking（コルレス撤退）を補完 |
| **規制裁定リスク** | ステーブルコイン発行体が銀行規制を受けずに類似業務 |
| **流動性管理の変質** | 企業の運転資金がステーブルコインで保有されると銀行預金が減少 |

**銀行の対応戦略:**
- JPMorganの**JPM Coin**（機関間決済）
- MUFGの**Progmat Coin**構想
- 自らステーブルコイン発行体になる方向性

**重要な留保:** ステーブルコインの準備金（米国債など）は依然として銀行システム内にあるため、**完全な非仲介化は起きない**。むしろレイヤーが増える可能性も。

## 6. 中央銀行政策の影響

### 政策金利チャネル

```
Fed利上げ
→ 米短期金利上昇
→ ドル保有の金利収益増大
→ ドル買い → ドル高
→ 新興国通貨安・資本流出
```

銀行業務への影響:
- **スワップポイント収益の変化** — 円売りドル買いスワップで銀行はドル金利を受け取る
- **フォワードレートの変化** — 金利平価に基づき調整される

### QE・QT（量的緩和・引き締め）

| 政策 | 為替への影響 | 銀行への影響 |
|---|---|---|
| QE（資産購入） | 通貨安圧力（通貨供給増） | 低ボラティリティ・低スプレッド |
| QT（バランスシート縮小） | 通貨高圧力 | 流動性タイト化、ファンディングコスト上昇 |

### 為替介入

中央銀行が**直接スポット市場で自国通貨を売買**する政策。

```
2022年9月 日銀介入: 約2.8兆円のドル売り円買い
→ 145円台 → 140円台に急騰（1日で5円動く）
```

銀行への影響:
- 介入はしばしば**事前通知なし**で発動 → ポジションの強制損切りリスク
- 介入後のリバウンドを狙うトレーディング機会

### フォワードガイダンス

「利上げパスを示唆する発言」だけで為替が動く。銀行の**金利・為替のシナリオ分析**がリスク管理の核心になる。

## 7. その他の重要論点

### A. 地政学リスクと通貨覇権

- **ドル覇権の構造的変化** — ロシア制裁・SWIFT排除がドル離れを加速。人民元・デジタル人民元（e-CNY）の台頭
- **有事の通貨** — 円・スイスフランは伝統的「リスクオフ通貨」。円は日本の対外純資産（世界最大）が背景
- **エネルギー価格と通貨** — 資源国通貨（CAD・AUD・NOK）は原油・鉄鉱石価格と連動

### B. 規制・バーゼル枠組み

- **バーゼルIII最終化（FRTB）** — トレーディングブックの資本賦課が増大。プロップFX取引を縮小させる方向
- **EMIR・Dodd-Frank** — デリバティブの中央清算義務化 → 証拠金コスト増大

### C. 技術・インフラ革新

| 変化 | 内容 |
|---|---|
| **CLS（Continuous Linked Settlement）** | ヘルシュタットリスクを62通貨で削減 |
| **SWIFT GPI** | 送金追跡・翌日着金を標準化 |
| **ISO 20022移行** | 決済電文のデータリッチ化。AML・制裁スクリーニングに影響 |
| **AIによるレートエンジン** | リアルタイムプライシングの自動化 |

### D. ALM（資産負債管理）と為替

銀行は外貨建て資産（外債・ドル建て貸付）を保有する一方、外貨調達は市場依存。

```
外貨調達手段:
1. 為替スワップ（短期が主流）
2. 外貨CD・外貨社債
3. ドル預金の吸収
```

**XCCYベーシス（通貨ベーシス）** — 円をドルにスワップするコストが理論値からずれる現象。2020年3月のコロナショック時は-200bpに達し、調達危機の先行指標となった。

## 整理：変数の相互作用マップ

```
地政学リスク
    ↓
中央銀行政策（金利・介入・QE）
    ↓
金利差 ←→ 資本フロー ←→ 経常収支 ←← 関税
    ↓              ↓
為替レート       ステーブルコイン（フロー代替）
    ↓
　銀行外為業務
　（スプレッド・ヘッジ需要・送金量・ボラティリティ）
    ↓
規制（バーゼル・FRTB）× 技術（ISO20022・AI）
```
