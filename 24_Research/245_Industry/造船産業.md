# 造船産業 — 体系的概観

## 1. 船のジャンル分類

| カテゴリ | 代表船種 | 特徴 |
|---|---|---|
| **バルカー** | ケープサイズ、パナマックス | 鉄鉱石・石炭・穀物を積む。最も汎用的 |
| **コンテナ船** | ULCS（超大型）| TEU数競争。港湾インフラと連動 |
| **タンカー** | VLCC、LNG船、LPG船 | 液体輸送。エネルギー安保に直結 |
| **自動車船（PCTC）** | 完成車専用 | 多層デッキ。トヨタ・現代の供給網 |
| **作業船・特殊船** | 海洋掘削・海底ケーブル・砕氷船 | 軍事・資源開発・インフラ |
| **防衛艦艇** | 護衛艦・潜水艦・揚陸艦 | 受注構造が民間と全く異なる |

## 2. 造船都市の立地条件 — 3要素

**① 鉄鋼**
造船の原材料コストの約40%が鋼材（船体用厚板）。製鉄所との近接または安価な調達ルートが必須。今治は中国・韓国産鋼材を海路で安く引ける。

**② 喫水（水深）**
大型船を進水させるには最低10〜15mの水深が必要。瀬戸内海は多島海で波が穏やかかつ深度が取れる天然の造船環境。

**③ 職人（技能集積）**
溶接・板金・配管・電気の熟練工は一朝一夕に育たない。今治・長崎・函館のような港湾都市は明治以来の技能の地域蓄積がある。

## 3. なぜ今治が強いのか — 資本主義的解釈

今治の強さは「船主資本の集積」というフィードバックループで説明できる。

```
オーナー(海運会社)が今治に集中
    ↓
造船所・舶用機器メーカー・ブローカーが周辺に集積
    ↓
情報・信用・コスト全部が域内で完結
    ↓
さらにオーナーが集まる（今治造船 / 正栄汽船 / 来島どっく...）
```

「船主街」として世界的に有名で、オーナーとヤードが車で30分圏内。シリコンバレーのVC-スタートアップ関係に似た地理的濃縮。

## 4. 素材の進化 — 造船界のジュラルミンはあるか？

航空機のジュラルミン相当の素材革命は造船では**起きていない**。理由：
- **サイズの経済** — 軽量化よりエンジン燃費改善の方がROIが高い
- **コスト** — チタン・CFRPは鋼材の10〜100倍
- **溶接との相性** — 鋼材は電弧溶接が使えるがアルミは難易度が高い

**部分的な進化：**
- **高張力鋼（HT鋼）** — 同強度でより薄く。軽量化と材料費削減を両立
- **二相ステンレス** — LNG船のカーゴタンク（−163℃対応）
- **腐食防止コーティング** — 船底塗料のナノ技術で摩擦抵抗を低減

**鉄鋼生産への影響**：高付加価値の厚板需要（JFEスチール、日本製鉄）は造船に依存。建造数減少が日本高炉産業に直撃する構造的依存関係がある。

## 5. 国際競争力の地図

### なぜ中国が強い？

| 要因 | 詳細 |
|---|---|
| **国家補助金** | 造船は戦略産業。安値受注でも国が補填 |
| **鋼材自給** | 宝武鋼鉄など世界最大の生産国。内製で材料コスト激安 |
| **賃金** | 熟練工の賃金が日韓の1/3〜1/5 |
| **スケール** | CSSC・CSIC（統合）で世界シェア50%超 |
| **一帯一路** | 中国系海運会社への優先発注という需要保証 |

### なぜ欧州は衰退したか？

1970〜80年代に価格競争から脱落。賃金上昇と環境規制コストが原因。
現在は**クルーズ船・フェリーなど高付加価値ニッチ**に特化。
- フィンカンティエリ（伊）= クルーズ船
- マイヤー・ヴェルフト（独）= LNG・クルーズ

## 6. LNG船 — 海上のエネルギー革命

**技術的特殊性：**
- 貨物温度が **−163℃** → タンクはニッケル鋼か膜式（GTT社の仏特許）
- 建造コストが通常バルカーの **5〜7倍**（高付加価値、日韓優位）

**「二刀流」としての意味：**
```
従来: 重油（HFO） → SOx・NOx・CO2を大量排出
LNG: 燃料としても使える → 海上輸送のCO2を約25%削減
```

IMO（国際海事機関）の2050年カーボンニュートラル目標でLNG燃料船の需要が急増。次世代燃料（アンモニア・水素・メタノール）への対応も設計段階から組み込む必要がある。

---

## 7. 便宜置籍船（FOC）— グローバル節税の仕組み

**3大FOC国：リベリア・パナマ・マーシャル諸島**

- 法人税・船員税が極めて低い
- 船員の国籍制限なし（安い労働力を使える）
- 登録手続きが簡素（オンライン登録すら可能）

日本オーナーの船でも「旗はパナマ、船員はフィリピン人、保険はロンドン」という構造が常態化。合法的なグローバル・アービトラージ。世界の商船隊の約70%がFOC船籍。

## 9. 国家予算と政策

日本の造船関連予算は約**3,000億円規模**（国土交通省・経産省・防衛省合算）。

- **GI基金（グリーンイノベーション）** — ゼロエミッション船開発
- **艦艇建造費** — 護衛艦1隻で約1,000〜1,500億円
- **造船業革新補助金** — DX・ロボット導入支援

中国・韓国の補助金は「見えない補助金」（土地・電力・融資）が多く実態把握が難しい。

## 10. ロボット革命

造船の最大ボトルネックは**溶接工**。一隻の船に数万カ所の溶接が必要で熟練工不足が業界全体の課題。

現在進行中の自動化：
- **溶接ロボット** — 平板部はほぼ自動化済。曲面・狭隘部が課題
- **ブロック搬送AGV** — 数百トンの鋼鉄ブロックを無人搬送
- **デジタルツイン** — 設計〜進水まで3D仮想造船所でシミュレーション
- **ドローン検査** — 船内タンク・外板の目視検査代替

## 11. 造船 × AI

**Noahlogy**（ノアロジー）が注目のスタートアップ。船舶データ解析・最適運航AIを開発。

造船×AIの主な応用領域：
- **設計自動化** — 要件→初期設計の生成
- **需給予測** — バルチック運賃指数の予測モデル
- **予知保全** — IoTセンサーで機関故障を事前検知
- **最適航路** — 燃費・気象・海峡混雑を統合最適化

韓国HD現代は自律航行船開発子会社`Avikus`を保有。今後は「作る」から「船のライフサイクル全体をデータで管理する」方向にシフト。

## 12. アメリカはなぜ参加しないのか — ジョーンズ法の呪縛

**ジョーンズ法（1920年制定）の制約：**
```
米国の港間を運ぶ船は
→ 米国で建造
→ 米国籍
→ 米国人船員
でなければならない
```

結果：
- 米国造船所は国際競争にさらされない → 技術革新・コスト競争力が育たない
- 米国の建造コストは日韓中の **5〜8倍**
- 廃止できない理由：海運労組・造船労組・海軍族議員の政治的連合

**軍事特化の結果**：民間商船建造能力は実質消滅。ウクライナ戦争以降、艦艇増産の必要性が高まる中でアメリカの造船能力不足が安全保障上の問題として浮上中。

## 全体構造

```
地政学・エネルギー転換
        ↓
  船の需要 (LNG・コンテナ・軍艦)
        ↓
  どこで作るか (中韓が量、日本が品質)
        ↓
  立地条件(鉄・水深・職人) × 国家戦略(補助金・規制)
        ↓
  テクノロジー(素材・ロボット・AI)
        ↓
  誰が所有し誰が旗を掲げるか (FOC・金融構造)
```

造船は「重工業」に見えるが、実態は**金融・地政学・エネルギー・労働・テクノロジーが交差するプラットフォーム産業**。今治が最強な理由も、単に船を上手く作るからではなく「船主資本・造船・舶用機器・保険・ブローカー」のエコシステムを地理的に独占しているから。
