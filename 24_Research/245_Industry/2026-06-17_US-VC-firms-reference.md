# 米国主要VCファーム 総合リファレンス2025-2026

> 作成日：2026-06-17 | カテゴリ：Industry（VC・投資業界）

---

## TL;DR

米国VC業界は2021-22年のバブル崩壊後、2024-25年にかけてAIブームで復活。規模・ステージ・セクターで完全に棲み分けが進んでいる。シード特化（First Round、Spark）、グロース/SaaS（Insight）、深層技術（Lux）、フィンテック特化（Ribbit）、そしてヘッジファンドとの境界を崩すクロスオーバー（Tiger、Coatue）など多様な戦略が共存する。SoftBankビジョンファンドはその規模と失敗で業界の常識を変えた存在。

## 特別解説①：SoftBank Vision Fund

| 項目 | 内容 |
|------|------|
| **設立** | Vision Fund 1：2017年。Vision Fund 2：2019年 |
| **ファンド規模** | VF1：**$100B**（当時史上最大）。VF2：約$56B（主にSoftBank自己資本） |
| **総AUM** | ピーク時$134B（2023年6月） |
| **創業者・主要人物** | 孫正義（Masayoshi Son、SoftBank創業者）、Rajeev Misra（VF1運用責任者、その後独立） |
| **主要LP（VF1）** | サウジアラビア公共投資ファンド（PIF：**$45B**）、UAEムバダラ投資（$15B）、Apple、Foxconn、Qualcomm、Sharp |
| **投資手法** | 「勝者を選んで資金を洪水のように注ぐ」——業界常識を超えた超大型ラウンドで市場支配力を買う戦略 |
| **有名投資** | Arm（IPO2023）、Uber、Slack、DoorDash、ByteDance、Coupang、WeWork |

### 論争・失敗事例

| 案件 | 概要 |
|------|------|
| **WeWork** | 総投資額**$16B**。IPO失敗、企業価値$47B→$2.9B→破綻。最大の失敗例 |
| **VF1累積損失** | 最大**$18B**の損失計上 |
| **VF2損失** | 2024年に$21B損失 |
| **構造的問題** | LP（Saudi PIF等）への年間利回り保証（クーポン支払い）が存在。GPはクーポンを賄うため短期・リスク選好的投資を強いられる → LP-GP間の利益相反 |
| **Credit Suisse問題** | 「安全・分散型」として販売したファンドがVFポートフォリオ企業に高集中していたことが発覚 |

### 現状（2025-2026年）
孫正義はAI投資に軸足を完全移行。Arm株式の価値上昇で巻き返し中。VF体制よりSoftBank本体の自己資本でAI直接投資（特にOpenAI等）にシフト。

## 特別解説②：Tiger Global ヘッジファンド＋VC ハイブリッドモデル

### モデルの構造

```
Tiger Global Management
├── 公開市場部門（ヘッジファンド）
│   ├── ロング/ショート戦略
│   ├── ロングフォーカス戦略
│   └── クロスオーバー（IPO前後を跨ぐ）
└── プライベート投資部門（VC・PE）
    ├── PIP（Private Investment Partners）シリーズ
    └── アーリー〜レイトステージスタートアップ
```

### 差別化要因

| 要素 | 内容 |
|------|------|
| **スピード重視** | DDを最小化し、素早い意思決定と大型チェックで勝負（従来VCの逆） |
| **ハンズオフ** | 取締役会参加を求めず、経営に干渉しない（パッシブ投資家として機能） |
| **フォロースルー** | プライベートからIPO後の公開市場まで同じ企業を継続保有できる |
| **グローバル視点** | 米国・中国・インド・東南アジアに同時展開（2010年代） |

### 2021-22年バブルでの失敗と2025年の再起

- ピーク時AUM $58.5B → $26.6B（2025Q1）まで縮小
- PIP XV（$12.7B）・XVI（$6.7B）のメガファンドは大幅評価減
- 2025年：PIP XVII で$2.2Bと大幅縮小。「スモール・アンド・ビューティフル」戦略に回帰
- 初期の小規模ファンド（各$3B未満、投資件数50件未満）のIRRは23%——復元目標のベンチマーク
