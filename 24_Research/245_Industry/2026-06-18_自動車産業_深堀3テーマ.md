# 自動車産業 深堀リサーチ：全固体電池・スズキインド・BYD
作成日：2026-06-18

---

## テーマ①：トヨタの全固体電池戦略

### TL;DR
トヨタは2027〜28年に全固体電池の限定量産を目指す「世界初量産」レース最右翼。出光興産との硫化物系電解質協業と特許数世界トップが強み。ただし「遅延の歴史」があり、中国が国家資本で猛追している。成功すれば「EVゲームのルール自体を塗り替える」技術だが、リスクも高い。

---

### なぜ全固体電池は重要か

現在の主流であるリチウムイオン電池（液体電解質）の弱点を全て解決できる可能性がある：

| 比較項目 | 現在（液体電解質LiB） | 全固体電池（SSB） |
|--------|------------------|---------------|
| 航続距離 | 400〜700km | **最大1,000km**（+50%） |
| 充電時間 | 30〜60分 | **10分**（10→80%） |
| 発火リスク | あり（液体が可燃性） | **大幅低減**（固体は燃えない） |
| 低温性能 | 冬季に大幅劣化 | 改善 |
| バッテリー寿命 | 10〜15年 | 理論上**40年以上** |
| エネルギー密度 | 250〜300Wh/kg | 400〜500Wh/kg（目標） |

> 全固体電池が量産できれば、「EVは充電が遅く・冬に弱い」という最大の懸念が消える

---

### トヨタの開発状況と競合優位性

#### 出光興産との戦略的協業（2023年10月〜）

| 役割 | 内容 |
|------|------|
| **トヨタ** | 全固体電池の車両設計・パック技術・総合統括 |
| **出光興産** | **硫化物系固体電解質**の量産技術（石油化学の知見を応用） |

- 両社は全固体電池および硫化物固体電解質の特許保有数で**世界トップクラス**
- 出光は2027年から硫化リチウム（Li₂S）大型製造装置を稼働、2030年に**1,000トン/年**（5〜6万台分）を目標
- 住友金属鉱山とも正極材の量産で共同開発契約を締結（2025年10月）

#### ロードマップ

| 時期 | 予定 |
|------|------|
| 2027〜28年 | **全固体電池搭載EV を限定量産**（年間数万台規模）。高価格帯モデルから先行 |
| 2030年 | 本格的量産体制へ移行。年間数十万台規模を目標 |
| 2030年代 | 全固体電池をEVラインナップの中核へ |

#### 技術アプローチ：なぜ硫化物系なのか

全固体電池には複数の方式があるが、トヨタが選んだ「**硫化物系**」は最もパワー密度が高い一方で製造難易度が高い：

| 電解質タイプ | 特徴 | 主な研究者 |
|-----------|------|---------|
| **硫化物系** | 高イオン伝導性・高出力、製造難易度高い | **トヨタ・出光**、Samsung |
| 酸化物系 | 安定・製造しやすい、電流密度低め | 村田製作所等 |
| ポリマー系 | 低コスト、低温性能課題 | ルノー等 |

### 「遅延の歴史」という最大のリスク

| 当初目標 | 後の発表 |
|---------|---------|
| 2020年量産 | → 2023年に先送り |
| 2023年量産 | → 2026年に先送り |
| 2026年量産 | → **2027〜28年に先送り**（現在） |

4回の先送りが信頼性に影響。「また延びるのでは？」という市場の疑念は拭えない。

**延びる理由の本質：**
- 固体電解質と電極の界面抵抗問題（固体同士は液体と異なり密着しにくい）
- 量産時の均一性の確保が極めて難しい
- リサイクル・コスト課題

---

### 競合状況：中国が国家資本で猛追

| プレイヤー | 状況 |
|----------|------|
| **トヨタ+出光** | 最も量産に近い。特許・技術力で先行 |
| **BYD** | 「ブレードバッテリー」（LFP）で現行技術を極め、固体電池も開発中 |
| **CATL（寧徳時代）** | 半固体電池を2024年から量産開始。全固体も開発加速 |
| **Samsung SDI** | 硫化物系で独自開発。2027年サンプル出荷目標 |
| **中国国家プロジェクト** | **年間830億円規模**の国家投資。BYD・CATLを後押し |

> 「中国は国家ぐるみでトヨタの技術アドバンテージを追い上げている」（日経XTech）

---

### 投資家・ビジネス視点でのポイント

- 成功すれば：「EVの不満点を全て解消」→ EVの普及が爆発的加速 → トヨタが次世代EV市場を主導
- 失敗すれば：「HV/PHVで稼いでいる間に中国BEVに侵食」→ トヨタの全方位戦略が「EVへの言い訳」だったと批判
- 全固体電池がトヨタの**最後の賭け**とも言える

## テーマ②：スズキのインド戦略

### TL;DR
スズキはインドで約40%のシェアを持つ「インドの国民車」。ただし2020年の50%超から低下中で、マヒンドラ・タタが急追。2030年に向けて年間400万台体制構築＋EV 6モデル投入でシェア50%回復を狙う。インドをグローバル輸出拠点に転換するのが最大の勝負手。

---

### インド市場の基本理解

| 指標 | 数値 |
|------|------|
| インド自動車市場規模 | 世界**第3位**（2023年に日本を抜いた） |
| 2024年度国内販売 | 過去最多（前年比増） |
| 成長ドライバー | 中間層の拡大・モータリゼーション進行中 |
| EV普及率 | 全体の約2〜3%（2025年時点）→急成長中 |

---

### Maruti Suzuki（マルチスズキ）の圧倒的地位

| 指標 | 数値（2024〜2025年） |
|------|-----------------|
| インド乗用車市場シェア | **約40%**（2024年10-12月期：40.7%） |
| 年間販売台数 | 約**180万台**（スズキのインド販売合計の55%） |
| インド国内工場 | グルガオン工場、マネサール工場、スズキモーターグジャラート（ハンサルプール） |
| 上場市場 | インド国内で上場（Maruti Suzuki India Ltd.） |

---

### なぜスズキはインドで勝てたのか：参入から40年の優位性

| 要因 | 詳細 |
|------|------|
| **1983年の早期参入** | インド政府との合弁「マルチ・ウドヨグ」として当時の規制の中で独占的に参入。40年分の「先行者利益」 |
| **インド向け小型車への特化** | 800cc〜1,200ccの低価格コンパクトカーを徹底設計。日本でのコスト最適化ノウハウをインドで展開 |
| **サービスネットワーク** | インド全土のディーラー・整備網が最も充実。地方農村部まで到達 |
| **低燃費CNG車の強み** | インドのガス価格環境に合ったCNG（圧縮天然ガス）モデルが大ヒット。他社より早く対応 |
| **政府との深い関係** | 長年の操業でインド政府・州政府との信頼関係が厚い |

---

### シェア低下の危機：マヒンドラとタタの台頭

| 社名 | 2020年シェア | 2025年シェア | 主な武器 |
|------|-----------|-----------|--------|
| **Maruti Suzuki** | 50%超 | **約35〜40%** | 小型・コンパクトカー全般 |
| **Mahindra** | 約6% | **約13%** | SUV（スコーピオ、タール、XUV700）、EV急成長 |
| **Tata Motors** | 約5% | 約10% | SUV、EVリーダー（Nexon EV等） |

**スズキのシェアが落ちた理由：**
- インド消費者の嗜好がコンパクトカー → **SUV・クロスオーバー**にシフト
- マヒンドラが強いSUVラインナップを連発
- EVでの出遅れ（タタが先行、マヒンドラが急成長）
- スズキが得意な「小型低価格帯」セグメント自体が縮小傾向

---

### スズキの2030年戦略：「400万台＋輸出拠点」化

#### ①生産能力：280万台→400万台（2030年）

| 拠点 | 計画 |
|------|------|
| **ハンサルプール新工場（グジャラート）** | EV専用ライン設置（2026年7〜9月めど）。年間25万台規模 |
| 既存マネサール・グルガオン | ガソリン・ハイブリッドの生産継続 |
| スズキモーターグジャラート | 拡張 |

→ 合計で年間**400万台超**の生産体制（現在世界最大規模の単一拠点群）

#### ②EV戦略：2030年までに6モデル投入

| モデル | 概要 |
|-------|------|
| **e Vitara**（eVX） | 初のBEV SUV。2025〜2026年インド発売→**100カ国に輸出**予定 |
| その後 | 2030年までに合計6つのBEVモデル投入 |
| 目標 | 2030年に自社販売の**15%をEVに**（インド） |

- e Vitara は「インドで作り、世界に売る」グローバルモデルとして設計
- インドのLFP（リン酸鉄リチウム）電池調達でコスト競争力を確保

#### ③「インド→世界輸出拠点」への転換

これがスズキの最大の勝負手：

> インドの低コスト生産力（人件費・部材）を活かし、EVを欧州・アフリカ・東南アジアに輸出することで、「インド帝国」をグローバル成長エンジンに変換する

- 日本の軽EV「Vision e-Sky」もLFP電池採用で200万円以下を狙う
- 日本向けモデルのバッテリーもインド調達で低コスト化

---

### スズキのインド投資規模

| 項目 | 金額 |
|------|------|
| Maruti Suzuki のEV投資（インド） | Rs 7,000クロール（約1,200億円） |
| ハンサルプール新工場全体投資 | 数千億円規模 |

## テーマ③：BYD（比亜迪）東南アジア進出戦略

### TL;DR
BYDは1995年設立の「電池屋」が世界最大のEV企業に化けた中国の怪物。東南アジアでは「タイを製造拠点・輸出ハブ」として2024年から稼働。インドネシア・マレーシア・ベトナムにも展開し、かつての日本車の牙城を崩壊させつつある。EU関税はPHEVシフトで迂回。2030年に「海外販売50%」を目標に世界制覇を狙う。

---

### BYDとはどんな会社か

| 項目 | 内容 |
|------|------|
| 正式名称 | **比亜迪（BYD Company Limited）** |
| 設立 | 1995年、**王伝福**（Wang Chuanfu）が深センで電池製造会社として創業 |
| 本社 | 深セン（広東省） |
| 売上高（2025年） | **8,040億元（約17兆円）**、前年比+3.46% |
| 事業構造 | ①BYD Auto（自動車）、②BYD Electronics（部品・組立）、③FinDreams（EVバッテリー・コンポーネント） |
| 自動車比率 | 売上の**80%超**が自動車事業（2023年以降） |
| EV販売 | 2024年にNEV（EV+PHEV）販売世界No.1 |
| 株主 | バークシャー・ハサウェイが2008年に約10%取得（2024〜25年に完全売却済み） |

---

### BYDの技術・ビジネス的優位性

#### ①垂直統合：バッテリーから車まで全部自社

BYDの最大の強みは「**電池から車まで全て自社で作れる**」こと：

| 製造能力      | 詳細                                               |
| --------- | ------------------------------------------------ |
| バッテリー     | 独自の「**ブレードバッテリー（LFP）**」。TeslaにもMegapack用バッテリーを供給 |
| 半導体（IGBT） | 自社でパワー半導体（IGBT）を製造できる唯一の自動車メーカー                  |
| モーター・電装   | 全て自社生産                                           |
| 車体・内装     | 自社設計・生産                                          |
| 充電インフラ    | 独自規格の充電ネットワーク                                    |

→ 他社に依存する部品コストがほぼゼロ = **圧倒的な価格競争力**

#### ②デュアル戦略：純EV + PHEV（DMi）の二刀流

- **純EV**：BYD シール、ドルフィン、アット3等。航続距離400〜600km
- **PHEV（DMi）**：「燃費モンスター」として知られる独自のプラグインハイブリッドシステム。ガソリン車並みのランニングコストでEV体験 → **「充電インフラがない東南アジア・欧州でも売れる」という布石**

---

### 東南アジア展開の全体図（2025年時点）

| 国 | 状況 | 販売シェア（2025） |
|----|------|---------------|
| **タイ** | 2024年7月に工場稼働（年15万台）。タイ最大の中国系EV拠点 | **8.3%**（前年5.0%→急上昇） |
| **インドネシア** | 10億ドル投資の工場（西ジャワ）、2025年末完成予定 | 約**5%**（販売前年比10倍） |
| **マレーシア** | 新工場建設発表（NEV工場、輸出拠点活用も検討） | — |
| **ベトナム** | BYD Auto Vietnam（完全子会社）、2024年参入 | — |
| **カンボジア** | シアヌークビルに新工場建設中 | — |

---

### タイが「ASEANの司令塔」になる理由

#### タイ工場の役割

| 機能 | 詳細 |
|------|------|
| 生産 | 小型EV「ドルフィン」を中心に年間**15万台**の生産能力 |
| 輸出① | **欧州輸出ハブ**：EU関税（中国製は計45%、タイ製は低関税）を回避するため、タイ工場から欧州にドルフィン輸出 |
| 輸出② | ASEAN各国への域内供給拠点 |
| 象徴効果 | 「EV後進国だったタイ」が「EV製造国」に転換 → タイ政府もBYD誘致を積極支持 |

> 2025年8月：タイ工場製PHEVをドイツ・ベルギー等欧州に900台超を初輸出（関税回避の実証）

---

### EU関税問題と迂回戦略

| 関税 | 内容 |
|------|------|
| 中国製EV → EU | 基本10% + 追加17%（BYD）= **計27%** |
| タイ製EV → EU | **大幅に低い**（ASEAN-EU自由貿易協定の恩恵） |
| BYDの対応 | タイで生産してEUに輸出 + PHEV比率を上げてEVより関税影響小さくする |

さらに：
- **トルコに新工場**を建設→トルコ経由で欧州市場へ
- **マレーシア工場**も欧州・中東輸出拠点として想定

### 販売の実態：日本車のシェアをどれだけ奪ったか

**タイ市場**

| 期間 | BYDシェア | 備考 |
|------|---------|------|
| 2022年以前 | 微小 | ほぼ日本車独占 |
| 2024年 | 約5% | |
| 2025年5月 | **8.3%** | 前年比+3.3pt急上昇 |

日本車は2019年にタイで50%超→2024年に約35%まで低下。BYDが主因。

**インドネシア市場**

- BYD ATTO 1が2025年10月に月間販売急伸
- 2025年1〜10月：BYD 30,670台（シェア4.8%）で6位
- EV全体シェアが2025年H1で約10%まで急上昇（前年比366%増）

|------|-------|-------------|-------------|
| 総販売台数 | 約427万台 | 550万台 | — |

### BYD vs 日本車：本質的な競争力の違い

| 視点 | BYD | 日本メーカー |
|------|-----|-----------|
| 価格 | 垂直統合で20〜30%安い | 調達コストが高い |
| EV開発速度 | 年間10モデル以上投入 | 年間1〜3モデル |
| ソフト更新 | OTA（無線更新）で常時改善 | 弱い |
| PHEVの完成度 | DMiは業界最高クラスの燃費 | 相対的に燃費劣後 |
| ブランド認知 | 新興国で急速に向上中 | 50年以上の信頼 |
| アフターサービス | インフラ整備中 | 圧倒的に充実 |

> 「価格と技術で押すBYDvs信頼とサービスで守る日本車」という構図。EVシフトが進めばBYD優位、インフラ未成熟な市場では日本車が粘る。

## 3テーマの関係性・総括

```
トヨタ全固体電池
  └→ 成功すれば：EVのコモディティ化に逆行、次世代で大逆転可能
  └→ 失敗すれば：BYDのLFP路線が事実上の業界標準に

スズキ・インド
  └→ インドがEV量産コストを下げる → 世界輸出で競争力確保
  └→ マヒンドラ・タタとのシェア争いが本格化
  └→ BYDがインド市場参入を本格化すれば、さらなる脅威

BYD東南アジア
  └→ 日本車の最後の「安全圏」だった東南アジアに侵入完了
  └→ タイ工場は欧州への迂回輸出拠点にもなる
  └→ 関税・規制をモグラたたきのように迂回しながら拡大
```

**大きな構図：「日本車のEV出遅れ」vs「中国EV産業の国家的成長」**

- トヨタ全固体電池が成功すれば日本の逆転の目
- スズキはインドという「EV化が遅い大市場」での要塞戦略
- BYDは「関税障壁も生産拠点の分散で突破」というグローバル生産ゲームを展開中
