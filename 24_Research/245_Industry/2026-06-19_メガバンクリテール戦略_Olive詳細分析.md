# 日本メガバンクのリテール戦略 ＆ 三井住友Olive 完全解剖

> 作成: 2026-06-19 | カテゴリ: Industry

---

## TL;DR

メガバンク3行のリテール戦略は2023〜2026年で「経済圏競争」フェーズに突入。先行するのは三井住友のOlive（700万アカウント超）で、SBIとの資本提携・PayPay連携・Vポイント統合を軸に独自エコシステムを構築。MUFGは「エムット」ブランドで追い上げ、2026年度中に全く新しいデジタルバンクを開業予定。みずほは楽天カード（15%出資）との提携で外部経済圏を借りてリテール強化。三行共通の課題は「ネット銀行・デジタルバンクとの競争」だが、メガバンクは店舗ネットワーク＋データ量＋信用力で差別化する戦略。

## 2. 三井住友 Olive（オリーブ）徹底解剖

### 2-1. 概要と会員数推移

Oliveは2023年3月にサービス開始。**銀行口座・クレジットカード・証券・保険を1つのアプリで管理**する個人向け総合金融サービス。

| 時期 | アカウント数 |
|------|------------|
| 2024年2月 | 200万突破 |
| 2024年7月 | 300万突破（ユーザーが確認したかった数字） |
| 2025年3月（サービス2周年） | **500万突破** |
| 2026年1月 | **700万突破** |
| 目標（2027年度末・5周年） | **1,200万アカウント** |

※「300万人」という数字は2024年7月時点での正確な数字。現在は700万超に拡大。

### 2-2. 若年層へのアプローチ

- **約半数（約49.2%）が20代以下**という圧倒的な若年層集中
- 10〜20代の満足度は9割超（Impress Watch, 2025年4月）
- SNS戦略が秀逸：媒体別KPI設計を行い、TikTok・Instagram・YouTubeで世代別コンテンツ展開
- 「高還元率より使いやすさ」を重視した若者の金銭感覚にフィット（日経Xtrend分析）
- 30代は189%成長、40〜60代超も200%超成長 → 若年層起点で全年齢に拡大中

### 2-3. Vポイント・Tポイントとの関係

- 2024年4月：**VポイントとTポイントが統合**（旧TポイントがVポイントに）
  - 三井住友カードのVポイント ＝ Tポイント加盟店（TSUTAYAなど）でもそのまま使用可
  - CCC（カルチャーコンビニエンスクラブ）との協業で統合ポイントとして再出発
- Olive口座保有残高100万円ごとにVポイント還元率+0.1%アップ（2026年4月〜）
- SBI証券でのクレカ積立（月間積立金額が2026年3月に1,000億円超）でもVポイント付与

### 2-4. PayPayとの関係

**三井住友はPayPayと提携している（2025年5月発表）。**

- 三井住友カードとソフトバンクが業務提携を正式発表（2025年5月）
- **VポイントとPayPayポイントの相互交換が2026年中にスタート**（等価交換）
- さらに2026年秋には「PayPay残高モード」をOliveフレキシブルペイに追加予定
  - 三井住友銀行アプリからPayPayのコード決済が直接できるようになる
  - Olive口座へのPayPay残高出金手数料が無料に
- 新CMにPayPayが登場し、グループ横断的に大々的に展開中

**ポイント**: PayPayはソフトバンク系（ヤフー・PayPay株式会社）だが、三井住友は競合関係より経済圏拡大を優先して提携。

### 2-5. SBI証券との連携（SMFG-SBIグループ資本提携）

**2022年6月23日に包括的資本業務提携を締結。**

- SMFGがSBIホールディングス株を第三者割当増資で引受け（27,000,000株、約796億円）
- SMFGのSBIホールディングスに対する議決権比率：約10%
- 株価は2,950円/株で設定
- 2020年4月の戦略的資本業務提携（スマートフォン証券・金融サービス仲介）が前身
- **住信SBIネット銀行とも2022年2月から協業**（三井住友信託銀行との連携）

**Olive×SBI証券の具体的連携：**
- OliveアプリからSBI証券口座を開設・管理可能
- 三井住友カードでSBI証券の投資信託を積立→Vポイント付与（クレカ積立）
- 月間クレカ積立金額が2026年3月時点で1,000億円超規模に拡大

### 2-6. Oliveポイント経済圏の全体像

```
【Olive経済圏マップ】

三井住友銀行（口座） ─── 三井住友カード（Vポイント）
        │                          │
        ├── SBI証券（クレカ積立）     ├── TポイントとVポイント統合
        ├── マネーフォワードME連携     ├── PayPayポイント⇔Vポイント交換（2026〜）
        ├── 保険（SMFG系列）          └── PayPay残高モード（2026秋〜）
        └── 住信SBIネット銀行（協業）

ポイントの流れ：
・日常の買い物（三井住友カード）→ Vポイント
・SBI証券でのクレカ積立 → Vポイント（最大5%）
・Olive口座残高 → Vポイント還元率アップ
・PayPay残高 ↔ Vポイント（相互交換）
・T系加盟店（TSUTAYA等）→ Vポイント利用可
```

## 3. MUFG・みずほの対抗軸

### 3-1. MUFGの「エムット」（empt）とは何か？

**エムット（empt）= MUFGグループ共通の新個人向けサービスブランド**（2025年5月発表）

| 要素 | 内容 |
|------|------|
| アプリ統合 | 三菱UFJ銀行アプリを刷新。口座・資産運用・カード情報を一元管理 |
| 共通ポイント | グループ共通ポイント「**エムットポイント**」を新設（複数サービスの利用で貯まる） |
| ランク制度 | ポイント還元・手数料優遇のステージランク制度を導入予定 |
| デジタルバンク | **2026年度後半**に全く新しいコンセプトのデジタルバンクを開業予定 |
| MAP | ウェルスナビと共同開発の「Money Advisory Platform」を搭載 |
| AIエージェント | Sakana AI・KDDIと協働でAIエージェント・金融特化LLMを開発 |
| システム基盤 | **Google Cloud**で勘定系システムを動かす（従来の銀行システムと全く異なる設計） |
| 対象顧客 | MUFGグループ約6,000万人の顧客データを活用 |

**エムットが「えむっと」と読まれる理由**: empt（エンプティ）をひらがな読みにして親しみやすさを演出したブランド名。

### 3-2. みずほの対抗戦略

**2024年11月：楽天カードとの資本業務提携（みずほが楽天カードに約15%出資）**

- **みずほ楽天カード**を新規発行
  - 利用でみずほポイント＋楽天ポイントのWポイント付与
  - 2025年7月〜「Wポイントプラン」開始
- **みずほポイントモール（2025年4月〜）**
  - みずほポイントを楽天ポイント・dポイントに交換可能
- 狙い：楽天経済圏（楽天市場・楽天モバイル等のユーザー）を入り口として本業金融へ誘導

**みずほの競争上のポジション：**
- Oliveやエムットと比べると自前の経済圏構築には出遅れ
- ただし楽天というメガプラットフォーム（楽天会員1億人超）を活用する合理的な判断
- 自前でポイント経済圏を作るより、既存大経済圏との接続を選んだ「外部提携型」モデル

## 4. 「リテールが強み」はメガバンクにとって本当か？

### 4-1. ネット銀行・デジタルバンクの台頭

| プレイヤー | 特徴 | メガバンクへの脅威度 |
|-----------|------|------------------|
| 住信SBIネット銀行 | 住宅ローン最大手級、低コスト | 高（住宅ローン） |
| PayPay銀行 | 決済連動、若年層 | 中（日常決済） |
| auじぶん銀行 | KDDI系、スマホ連動 | 中（通信系経済圏） |
| みんなの銀行（ふくおか） | 完全デジタルネイティブ | 中（Z世代） |
| SBI新生銀行 | 高金利・外貨 | 中（預金金利） |

**ネット銀行の優位性：**
- 金利が高い（定期預金・普通預金とも）
- 手数料が安い（ATM・振込）
- 口座開設が完全オンライン
- UIが洗練されている

### 4-2. メガバンクの対抗論拠

**「リテールが強み」という言説の実態：**
- 厳密には「規模が大きい」が「リテール収益率が高い」とは別の話
- 長年の低金利環境で住宅ローン・預金の利ザヤは薄く、純粋なリテール収益は苦しかった
- 金利上昇局面（2024〜）で住宅ローン収益が回復傾向

**メガバンクが持つ本当の強み：**
1. **信用力・安心感**: 大口取引・高齢者顧客は銀行の安定性を重視
2. **総合提案力**: 住宅ローン×資産運用×保険×相続を一体提案できる（Olive・エムットはこれを具現化）
3. **6,000万人規模のデータ**: AIと組み合わせることで個別最適な金融提案が可能
4. **店舗ネットワーク**: デジタルとリアルの「いいとこ取り」（エムットが明示的に謳う）
5. **法人リテールとの相乗効果**: 中小企業オーナーへの法人×個人一体提案

**対抗戦略の本質：**
- 「手数料・金利の安さ」でネット銀行に勝とうとしない
- 「ポイント経済圏×データ×総合提案」で顧客のLTV（顧客生涯価値）最大化を狙う
- Olive・エムットはどちらも「アプリを入り口に、複数サービスを横断させる」設計

### 4-3. 競争の「勝ち筋」分析

```
【2026年 日本銀行業リテール競争構図】

メガバンク（Olive/エムット） vs ネット銀行 vs 通信系銀行（PayPay/au/ドコモ）

・三井住友Olive：先行優位、若年層・PayPay・SBI軸
・MUFG エムット：規模最大、デジタルバンク開業で本格参入（2026年度）
・みずほ：楽天経済圏との連携で外部リソースを活用
・ネット銀行：金利・手数料コスト優位は維持
・通信系：スマホ利用データとの融合が強み

結論：完全な「勝者」はなく、細分化した顧客層に応じたポジション争いが続く。
若年層はOlive・PayPay銀行系が取り込み、中高年層・資産形成層はMUFGが狙う。
```
