# フィンテック（決済×API）産業分析

> 調査日: 2026-04-10

---

## TL;DR（この産業を一言で）

**「金融機能をAPIで部品化し、あらゆるサービスに組み込めるようにした産業」**。
決済・証券・融資が「インフラ」になり、開発者が数行のコードで金融機能を実装できる。
Stripe（決済）・PayPal（ウォレット）・Alpaca（証券）はそれぞれ異なるレイヤーを担う。

## 2. バリューチェーン構造（Payment×API）

```
[顧客・エンドユーザー]
        ↕
[アプリ / EC / サービス]  ← ここにAPIが刺さる
        ↕
[決済・金融インフラAPI]  ← Stripe / Alpaca / Plaidなど
        ↕
[カード会社・銀行・取引所]  ← Visa/Mastercard, 銀行, 証券取引所
        ↕
[中央銀行・規制当局]
```

**キーコンセプト: "Finance as Infrastructure"**
→ 金融機能を自社で持たなくても、APIを呼ぶだけでアプリに実装できる。

## 3. 主要プレイヤー比較

### Stripe — 決済インフラの王者

| 項目 | 内容 |
|------|------|
| 創業 | 2010年（Patrick・John Collison兄弟） |
| 本質 | **開発者向け決済API**。カード決済・ACH・ウォレット・BNPLを統合 |
| 対象 | SaaSや EC事業者が「数行のコードで決済実装」するための基盤 |
| 収益モデル | 成功課金：**2.9% + $0.30/件**（国際は+1%） |
| 拡張サービス | Radar（不正検知）・Sigma（SQL分析）・Atlas（会社設立$500）・Connect（マーケットプレイス決済） |
| バリュエーション | 約$650億（2023時点、非上場） |

**一言:** StripeはAWSの決済版。「決済を難しくしない」を哲学に、2行のJSでカード入力フォームが動く。

---

### PayPal — デジタルウォレットの老舗

| 項目 | 内容 |
|------|------|
| 創業 | 1998年（Elon Musk・Peter Thielらが関与、eBay傘下→2015年独立） |
| 本質 | **消費者向けデジタルウォレット** + 加盟店向け決済処理 |
| 対象 | 一般消費者の「ネット送金・購入」と加盟店の「決済受け入れ」 |
| アクティブアカウント | **4.34億** |
| 収益（2025） | **$318.9億**（前年比+4.79%） |
| 傘下サービス | Venmo（P2P送金）・Braintree（企業向け）・Xoom（海外送金）・BNPL |
| 2025最新動向 | 「PayPal Open」(統合BizHub)・「PayPal World」(クロスボーダー)をローンチ |

**一言:** PayPalはStripeより古く、一般消費者側から金融を民主化してきた。今はウォレット＋ショッピングプラットフォーム化を目指している。

---

### Alpaca — 証券×APIの新星

| 項目 | 内容 |
|------|------|
| 創業 | 2015年（YCombinator卒業） |
| 本質 | **Broker-as-a-Service（証券仲介のAPI化）** |
| 対象 | ① 個人アルゴトレーダー ② 証券機能を組み込みたいFinTechスタートアップ |
| 主力API | **Trading API**（個人が株・暗号資産を自動売買） / **Broker API**（他社アプリに証券機能を埋め込む） |
| 取扱 | 米国上場株・ETF・オプション・暗号資産 |
| 収益モデル | 取引手数料ゼロ（決済手数料/PFOFなど間接収益） |
| ライセンス | FINRA/SIPC登録（米国証券業者） |

**一言:** AlpacaはStripeの証券版。「Robinhoodのような投資アプリを自分のサービスに組み込みたい」開発者のための基盤。

## 5. 技術トレンド・ディスラプション

- **Embedded Finance（組み込み金融）**: 非金融サービス（EC・SaaS）が自社で金融機能を持つ。Stripeがその主役
- **Open Banking**: 銀行APIの開放義務化（欧州PSD2、日本も推進）。Plaid・TrueLayerが仲介
- **AI×Fraud Detection**: 不正検知にMLを活用（Stripe Radar等）
- **BNPL（後払い）**: Affirm・Klarna・Afterpay。Stripeも統合済み
- **Stablecoin決済**: PayPalが独自Stablecoin（PYUSD）を発行。クロスボーダー低コスト化
- **Agentic Finance**: AIエージェントが自律的に決済・投資を実行する時代が到来しつつある

---

## 6. 規制・政策

- **日本**: 資金決済法・金融商品取引法。Stripeは日本法人あり、Alpacaは日本向け未対応
- **米国**: FINRA（証券）/ FinCEN（AML）/ CFPB（消費者保護）
- **EU**: PSD2（決済）/ MiCA（暗号資産）
- 各国でオープンバンキング推進 → 銀行との競合・連携が加速

## 7. ビジネス・投資機会

| 機会 | 詳細 |
|------|------|
| SaaS × 決済埋め込み | StripeのConnect/Billingを使い、自社SaaSに決済機能を追加して収益多様化 |
| 投資アプリ構築 | Alpacaの Broker APIで証券機能を持つアプリを開発（日本ではRobinhood的サービスが少ない） |
| クロスボーダー送金 | PayPal World等の恩恵、または競合サービス（Wise・Revolut）参入機会 |
| フィンテック投資 | 決済API関連企業への注目（Stripe上場待ちのIPO候補） |
