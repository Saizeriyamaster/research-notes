# 日本自動車産業 総合リサーチ
作成日：2026-06-18

---

## TL;DR

日本の上場自動車メーカーは世界販売の**27%**を占め、トヨタが圧倒的No.1。各社は国内比率10〜22%と海外依存が高く、EVシフトの遅れで中国・東南アジアでシェアを失いつつある。日産は90年代・現在と2度の経営危機に陥り、カルロスゴーンの劇的再建が歴史に残る。ホンダ・日産・三菱の経営統合協議は2024年12月に始まったが翌年2月に破談。各社はEV戦略を急いでいるが出遅れ感が強い。

## 3. 三菱・ホンダ・日産 アライアンス年表

### 背景：なぜ3社が組もうとしたのか

**①ルノー・日産・三菱アライアンス（1999〜現在）**
- 1999年：ルノーが日産株37%取得 → ゴーン主導でアライアンス成立
- 2016年：日産が三菱自動車に**2,370億円**を出資（34%保有）→ 三菱はアライアンス正式参画
- 現在：ルノー・日産・三菱の3社アライアンス（生産・調達・技術の相互活用）

**②ホンダ・日産 統合協議（2024〜2025）**

| 日付 | 出来事 |
|------|------|
| 2024年12月 | ホンダ・日産が経営統合基本合意書を締結、三菱自動車も覚書締結 |
| 2025年1月 | 三菱自動車が参画の可否を検討中 |
| **2025年2月13日** | **3社協議を完全中止・覚書解約を合意** |

**なぜ破談したのか**
- 日産の経営危機が想定以上に深刻で、対等な統合が困難
- 電動化時代に向けた「意思決定スピード優先」の判断
- 実質的に「ホンダが日産を救済する構図」となり、条件面で折り合わず
- EVシフトへの投資を独自ルートで確保する方が合理的という判断

## 4. 日産の経営不振：2度の危機の構造

### 4-1. 1990年代の経営危機

**原因：バブル崩壊×慢心×構造的過剰**

| 要因 | 内容 |
|------|------|
| **バブル崩壊（1991〜）** | 国内市場急縮小。設備・人員の過剰が一気に顕在化 |
| **シーマ現象の後遺症** | 80年代後半のバブル期に「シーマ現象」で絶好調。好調に慢心し、構造改革を先送り |
| **商品力の低下** | デザイン・商品戦略の失敗が重なり販売不振 |
| **有利子負債の肥大** | **2兆円超**の有利子負債 |
| **利益構造の悪化** | 1999年3月期：**純損失6,844億円**（当時上場企業ワースト） |

> 「いつ倒産してもおかしくない」状況まで追い詰められた

---

### 4-2. カルロスゴーンによる経営再建（1999〜2005年頃）

**背景：1999年にルノーが日産株37%を取得し、COOとしてゴーンを送り込む**

#### 「日産リバイバルプラン（NRP）」の具体策

| 施策 | 詳細 |
|------|------|
| **9つのクロスファンクショナルチーム** | R&D・製造・調達・営業・組織設計など横断的なコスト削減WG。部門間の「縦割り」を破壊し成果責任を明確化 |
| **国内5工場閉鎖** | 村山工場（東京都）、宇治工場（京都府）、港工場（愛知県）等を閉鎖 |
| **2.1万人の人員削減** | 全従業員の**14%**を削減 |
| **系列（ケイレツ）の解体** | 取引先を**1,145社→600社**に半減、購買コストを**20%削減**。日本的系列慣行を公然と否定 |
| **資産売却** | 日産宇宙事業（ IHIへ売却）等の非中核資産を処分 |
| **22の新モデル投入** | ブランド復活のため集中的に新車開発・投入 |
| **財務目標の公約** | ①2000年度に黒字回転 ②2002年度に営業利益率4.5%以上 ③有利子負債を7,000億円以下に |

#### 結果

- 2001年3月期：**純利益3,310億円**（前年の損失から大逆転）
- 2003年6月：**有利子負債を完済**（予定より前倒し）
- 評価：「企業再建史上最も劇的な回復の1つ」（多くの経済学者）

#### ゴーンの経営手法の特徴
- **「コミットメント文化」の導入**：日本の集団責任文化を変え、個人の明確な達成目標・説明責任を設定
- **「コスト意識の徹底」**：感情的な系列取引を廃止し、全て競争原理で見直し
- **「異文化マネジメント」**：ルノーとの協調でグローバル調達のスケールメリットを活用
- 一方で「収益性優先・長期投資軽視」という負の遺産も残した（後述）

---

### 4-3. 現在（2024〜2025年）の経営不振

**ゴーン時代の「負の遺産」＋新たな構造問題**

| 要因 | 内容 |
|------|------|
| **過剰生産能力** | グローバル生産能力500万台に対して販売は335万台（稼働率**70%を下回る**） |
| **北米依存の崩壊** | 最大市場の北米で在庫積み上がり・インセンティブ増加、2025年3月期に北米営業赤字441億円 |
| **中国市場での敗北** | 2025年3月期で中国販売**12.2%減**。EVシフトに乗り遅れ、現地ブランド（BYD等）に駆逐 |
| **EVへの対応遅れ** | ゴーン時代のリーフ（2010年）は先行したが、その後継続投資を怠った |
| **資産の大規模減損** | 2025年3月期に北米・日本の工場等で**5,000億円超の減損** |
| **リストラ費用** | 人員削減等で**600億円超**のリストラ費用 |

#### 2025年3月期の業績（衝撃的な数字）

| 項目 | 数値 |
|------|------|
| 販売台数 | 335万台（前年比▲2.6%） |
| 連結売上高 | 約12兆円 |
| 連結営業利益 | **580億円**（前年比▲87.7%） |
| 特別損失 | **6,238億円**（減損＋リストラ） |
| 親会社帰属純損失 | **▲6,709億円** |

#### 経営再建計画「Re:Nissan」（2025年5月発表）
- 変動費2,500億円＋固定費2,500億円の合計**5,000億円削減**
- 生産工場を2027年度までに**17→10拠点**に集約
- 2024年度比で計**2万人の人員削減**
- 2026年度中の黒字転換を目標

## 5. 三菱自動車の国内事業損失について

### なぜ三菱の国内事業は苦しいのか

**ユーザー指摘の損失数字について**
検索で確認できた数字では、2025年度（FY2025）通期で**当期純利益+100億円**（前年比75.6%減）、4〜12月の累計では**最終赤字44億円**。ただし特定の期（特に4〜12月を含む中間期）で**2,439億円の特別損失含む赤字**が計上されており、国内事業セグメントに着目すると大幅な損失になっている可能性がある。

### 国内販売が苦しい構造的な理由

| 要因 | 内容 |
|------|------|
| **商品ラインナップの極端な縮小** | 国内では軽自動車（eKワゴン系）と一部SUV（エクリプスクロス等）のみ。セダン・ミニバン等は全廃 |
| **ASEAN集中戦略の裏側** | タイ・フィリピン・オーストラリアに経営資源を集中させた結果、日本市場への投資が手薄 |
| **認知度・ブランド力の低下** | 広告費削減・新車投入ペース低下で国内での存在感が著しく低下 |
| **軽自動車燃費不正問題（2016年）の後遺症** | 2016年に軽自動車の燃費データ改ざんが発覚し、日本国内のブランドイメージに深刻なダメージ |
| **固定費の重さ** | 国内販売台数が11万台程度しかない一方、日本本社・開発機能・ディーラー網の固定費は存在する |
| **関税・為替の影響** | タイバーツ安で238億円損失、米国関税で474億円のマイナス（2025年度） |
| **品質対策費用** | 品質対策費用の増加がさらなる利益圧迫 |

> 本質的には「日本市場から事実上撤退しながら、完全撤退もできない中途半端な状態」が固定費負担として残り続けている構造問題。

## 6. 日産のPERが高い（または異常に見える）理由

### PERの基本とNISSANの現状

**PER = 株価 ÷ 1株当たり純利益（EPS）**

2025年6月時点の日産：
- 株価：約364円
- EPS：**マイナス**（純損失6,709億円）
- PER(予)：**▲2.3倍**（マイナスなので通常表示不能）
- PBR(実)：**0.26倍**（解散価値の1/4以下）

### なぜPERが「高く見える」または「おかしく見える」のか

#### ①赤字・超低収益期の数字はPERを歪める

> 「本来はもっと大きいはずの営業利益が小さいから」

これは正しい分析。

- **正常時の日産の営業利益**：2兆円規模の売上から通常は2,000〜3,000億円程度の営業利益が出るはずの規模
- **2025年3月期の現実**：営業利益580億円（前年比87.7%減）
- **特別損失による純損失**：6,709億円

→ 一時的な巨額特損（工場減損・リストラ費用）が純利益を大きく押し下げている。このため「来期の回復後の正常利益」で計算すると、むしろ割安に見える可能性もある。

#### ②市場は「回復期待」で株価を下支えしている

日産の株価が純損失の割に大きく下落しない（または一定水準を保っている）のは：
- 再建計画「Re:Nissan」への期待
- 2026年度の**営業利益1,300億円**予想（ポジティブに転換）
- ルノー・アライアンスの資産価値・ブランド価値の存在
- 解散価値（清算価値）が市場時価をかなり上回っている可能性

> **PER分析のポイント**：損失年度のPERは意味をなさず、投資家は「正規化EPS（Normalized EPS）」や「回復後のフォワードPER」で評価する。日産は現在「再建途上の特殊フェーズ」にあり、PBR0.26倍という超割安水準が株価の下値を支えている構造。

## 7. 各社のEV戦略

### トヨタ ─「全方位戦略（マルチパスウェイ）」

| 項目 | 内容 |
|------|------|
| 基本戦略 | EV・HV・PHV・FCEV・HFCVすべてを揃える全方位戦略。「EVだけでは世界の多様なニーズに応えられない」という立場 |
| 現在のEV | bZ4X（2022〜）、bZ3C等、bZシリーズを順次拡充 |
| 2026年 | bZ4X ツーリング投入予定 |
| 最大の賭け | **全固体電池**（2027〜2028年実用化目標）→世界初の量産化を目指す |
| 課題 | 中国市場でのEV化遅れで販売シェアが急低下。「全方位戦略」が「EV対応の言い訳」と批判される場面も |

---

### ホンダ ─「2040年EV/FCEV 100%」という野心的目標

| 項目 | 内容 |
|------|------|
| 基本目標 | **2040年までに全新車をEV・燃料電池車（FCEV）に**（業界最も野心的な目標の一つ） |
| 2026年 | 軽EV「Super ONE」発売予定（日本先行） |
| 商用EV | N-VAN e:（2023〜）が先行、商用から市場開拓 |
| 北米 | Honda Prologue（GMとの共同開発）投入 |
| 課題 | 日産との統合破談で独自EV投資を続ける必要。ソニーとのアファーラも開発中 |

---

### 日産 ─「EVの先駆者が出遅れた逆説」

| 項目 | 内容 |
|------|------|
| 歴史 | 2010年にリーフを世界初量産EVとして発売。一時は世界No.1 EV |
| 現在の主力EV | リーフ（B5グレード追加、55kWh）、アリア（クロスオーバーEV）、**サクラ**（軽EV、国内大ヒット） |
| 計画 | 2026年度までに**16車種**の電動車を投入 |
| 全固体電池 | **2028年度**実用化目標 |
| 課題 | リーフ成功後の投資継続が不十分で、テスラ・中国BYDに世代で遅れを取った。現経営危機がEV投資の足かせに |

---

### 三菱自動車 ─「日産プラットフォームで軽EV参入」

| 項目 | 内容 |
|------|------|
| 現在 | **eKクロスEV**（日産サクラと同一プラットフォーム・OEM）を販売中 |
| 独自EV | 独自の大型EV開発への投資は限定的 |
| PHV | アウトランダーPHEVは国内PHV市場で長年トップクラス |
| 課題 | 経営余力が乏しく、独自EV開発は日産・ルノーアライアンスへの依存が前提 |

---

### スズキ ─「軽EV戦略と新興国特化」

| 項目 | 内容 |
|------|------|
| 2026年 | 軽EV「Vision e-Sky」市販化目標。LFP電池採用で**200万円以下**を目指す |
| インド戦略 | Maruti Suzuki経由でインド向けEV開発中 |
| 課題 | EVで利益を出すことが難しい軽自動車セグメントでのEV化は収益性が問題 |

## 8. 産業全体のまとめ：東南アジアでの逆風

**「日本車の牙城」だった東南アジア市場で何が起きているか**

- 2019年まで東南アジア（タイ・インドネシア・シンガポール）でのシェアは**50%超**
- 2024年には**35%前後**まで低下
- 中国BYD・吉利（Geely）等が安価なEVで猛追
- 日本メーカーはガソリン車では優位だが、EV投入が遅く若い消費者に中国ブランドが浸透

> 「かつて東南アジアは日本車が支配していた。今は、インドネシアですらほぼ全ての車が日本車だった時代（2019年）から、中国ブランドが急速に食い込んでいる」（Bloomberg）
