## 1. なぜ航空会社はデフォルトしやすいのか

### 構造的な負け筋

航空会社は「高固定費 × 変動収益 × 外部ショック」という最悪の組み合わせを持つ。

| コスト項目 | 特徴 |
|---|---|
| 燃料費 | 総コストの20〜30%。原油市況に直結、コントロール不能 |
| 人件費 | パイロット・整備士は資格が必要。削減困難 |
| 機体リース | 長期契約。不況でも返却ルールは厳しい |
| 空港使用料 | スロット割当で固定化 |
| 維持費・保険 | 規制で最低水準が定められている |

- **旅客1人を追加で乗せる限界費用はほぼゼロ**なのに、固定費の塊なので座席が1つ余るほど赤字が膨らむ
- **需要は景気に強く連動**する（ビジネス渡航 > 観光）。リーマンショック・COVID-19で一気に蒸発
- **価格競争が激しく、運賃はコモディティ化**。差別化が難しい
- **高レバレッジ**：機体調達（1機100〜500億円）のため大量借入が標準

### 有名な破綻例

| 会社 | 破綻時期 | 主因 |
|---|---|---|
| Pan Am | 1991 | 湾岸戦争・燃料高騰・規制緩和後の競争激化 |
| TWA | 2001 | 9.11後の需要蒸発 |
| JAL | 2010 | 累積赤字・過剰な年金債務・リーマンショック |
| Air Berlin | 2017 | ライアンエアとの競争・資金繰り悪化 |
| Flybe | 2020 | COVID-19直撃 |

### ウォーレン・バフェットの名言

> "If a far-sighted capitalist had been present at Kitty Hawk, he would have done his successors a huge favor by shooting Orville down."  
> — ライト兄弟の初飛行を見た投資家がいたなら、飛行機を撃ち落としていれば後世の投資家を救えた

バフェットはデルタなど航空株を2020年のCOVID直後に全売却し、約3,600億円の損切りをした。

## 2. 航空管制（ATC）はなぜ人力なのか

### 現状

世界の航空管制（Air Traffic Control / ATC）は、**管制官（人間）が最終意思決定者**として機能している。日本では国土交通省 航空局が管轄。

### なぜ完全自動化・AI化が進まないのか

**① 安全規制の要件**
- ICAO（国際民間航空機関）・FAO・JCAB は「ヒューマン・イン・ザ・ループ」を前提に設計されている
- AIが誤判断した場合の**法的責任の所在**が未整備

**② 非定型事象への対応**
- 緊急宣言（Mayday）、医療事案、テロ疑い、機体異常など、プロトコル外の判断が頻繁に起きる
- 「99.99%のケース」はアルゴリズムでいけるが、残り0.01%が命取りになる業界

**③ 既にAIアシストは導入されている**
- TCAS（Traffic Collision Avoidance System）：機体同士が自動で回避指示
- MLAT（多点測距）・ADS-B：リアルタイム位置追跡
- AI需要予測によるスロット事前割当
- NASA・EUROCONTROLが研究する「自由飛行（Free Flight）」コンセプト

### AIが代替可能な部分 vs. 困難な部分

| 領域 | AI化の現状 |
|---|---|
| ルーティン誘導（高度・ルート変更指示） | 自動化進行中（NextGen/SESAR計画） |
| 滑走路の離着陸許可 | 補助ツールあり。最終判断は人間 |
| 緊急・非定型事象 | 人間必須 |
| 天候回避ルート計算 | AI活用が急速に進む |

**結論**：完全自動化は技術的には可能に近づいているが、**規制・責任・社会的受容**の問題が先行している。今後10〜20年でハイブリッド型（AI監視 + 人間承認）が標準になると見られる。

## 3. LCCのビジネスモデル

### サウスウエスト航空が原型

LCCの元祖は1960年代米国のサウスウエスト航空。ライアンエアはこれを模倣・過激化させた。

### 7つのコスト削減ドライバー

| 施策 | 効果 |
|---|---|
| **ポイント・トゥ・ポイント路線** | ハブ経由なし。乗継コストゼロ |
| **第2空港使用**（スタンステッド、シャルルロワ等） | 着陸料がヒースローの1/5〜1/10 |
| **機材標準化**（A320一本、737一本） | 整備費・訓練費・部品在庫を激減 |
| **高稼働率**（ターンアラウンド25分） | 1機あたりの日次フライト数を最大化 |
| **機内サービス全廃** | ギャレー縮小 → 座席数増加 |
| **紙チケット廃止・直販** | GDS手数料ゼロ、代理店マージンゼロ |
| **乗務員の柔軟ローテーション** | 組合規制が緩い国で優位 |

### ライアンエアのKPI（FY2024）

| 指標 | 数値 |
|---|---|
| 総収益 | €13.4B |
| 旅客収益 | €9.1B（68%） |
| アンシラリー収益 | €4.3B（32%） |
| 純利益 | €1.92B |
| 旅客数 | 1.84億人 |

## 4. ライアンエアの「ケチ戦略」の経済カラクリ

### 表向きの安さ ≠ 本当の安さ

LCCの運賃設計は「**フェンシング（Fencing）**」と呼ばれる価格差別の仕組み。

```
表示運賃（超安い）
  + 座席指定料
  + 手荷物料（少しでもサイズ超えると高い）
  + 優先搭乗料
  + チェックイン料（空港カウンター）
  + クレジットカード手数料
  + 機内食・飲料
  = 実際の支払い（フルサービスと大差ないことも）
```

**なぜサイズ規制が重要なのか？**

- 機内持込サイズを厳格に設定し、数cm超えると課金
- 20kgスーツケースを預けると€45〜€70（事前購入で€15〜）
- 荷物は**限界費用がほぼゼロ**なのに数十ユーロの収益
- 空港での課金は「罰金型」で心理的に払わせやすい

**トイレ有料化計画（2009年）**

- ライアンエアCEO マイケル・オリアリーが「1ユーロのトイレ代」を提案
- 規制・実装コストの問題で実現せず（トイレ撤去は航空法上問題）
- プレスリリースとしての「炎上マーケティング」効果は絶大

### アンシラリー収益の本質

> 「座席は広告で、本当の商品は付帯サービス」

ライアンエアはアンシラリー収益に20のパラメータを使ったリアルタイム価格調整を導入。アンシラリー比率は24%→34%に上昇（2024年時点）。

### 第2空港戦略

- ロンドン・スタンステッド（ヒースローから60km）
- ブリュッセル・シャルルロワ（市内から55km）
- フランクフルト・ハーン（市内から120km）

空港側も「発着数さえ確保できれば」と格安で貸す。空港収益はショップ・駐車場・ホテルから。

## 5. サーチャージとは何か

サーチャージ（Surcharge）= 基本運賃に追加される付加料金の総称。

### 主な種類

| 種類 | 内容 |
|---|---|
| **燃油サーチャージ（YQ/YR）** | 燃料費の変動分を運賃に転嫁。原油価格連動で毎月改定。最大で数万円 |
| **空港施設使用料（Airport Tax）** | 旅客ターミナルの建設・維持費用。国・空港によって異なる |
| **保安サービス料** | 手荷物X線検査・保安員の費用 |
| **国際観光旅客税（出国税）** | 日本：1人1,000円（2019年〜）。主に観光促進財源 |
| **為替サーチャージ** | 一部路線で外貨建て運賃の変動を転嫁 |
| **通関・入国税** | 各国政府が徴収する入国手数料 |

### 燃油サーチャージの仕組み

```
シンガポールケロシン価格（SIN価格）を基準
  → 月次で2ヶ月前の平均を参照
  → 各航空会社が独自の計算式で設定
  → IATA GFAXとして共有（カルテルにならないよう）
```

**旅行者として注意**：格安運賃に燃油サーチャージを加えると、フルサービス運賃を上回ることも。チケット購入前に「全込み価格」で比較すること。

## 6. 航空機燃料の種類

### メイン燃料：ジェット燃料（Jet Fuel）

| 種類 | 主な用途 | 特徴 |
|---|---|---|
| **Jet A-1** | 国際線・大半の民間機 | 引火点>38℃、凍結点−47℃以下 |
| **Jet A** | 米国国内線 | 凍結点−40℃（Jet A-1より少し高い） |
| **Jet B** | 超寒冷地（カナダ等） | 揮発性高め。寒冷地での始動性向上 |
| **JP-8** | 軍用（米軍標準） | Jet A-1にコア腐食防止剤を追加 |

**ケロシン系**（灯油に近い炭化水素）で、揮発性はガソリンより低く安全性が高い。

### ガソリン系：Avgas（Aviation Gasoline）

- 小型プロペラ機・軽飛行機用
- **Avgas 100LL**（Low Lead）が主流
- ピストンエンジン用。ジェットエンジンでは使用不可

### 次世代：SAF（Sustainable Aviation Fuel / 持続可能な航空燃料）

- バイオマス（廃食油・農業残渣）や合成燃料から製造
- 従来ジェット燃料と混合使用（現在最大50%まで）
- CO₂排出量を最大80%削減可能
- 現在の価格は従来燃料の**3〜5倍**（スケールアップ中）
- IATA目標：2050年までにSAFで排出量半減

## 7. 空港税と空港の管理主体

### 空港の運営主体（日本）

日本の空港は大きく3種に分類される。

| 分類 | 例 | 管理主体 |
|---|---|---|
| **国管理空港** | 羽田・福岡・那覇など28空港 | 国土交通省（航空局） |
| **特定地方管理空港** | 花巻・富山など4空港 | 地方公共団体 |
| **会社管理空港** | 成田（NAA）・関空（KIAC）・中部 | 株式会社（国が株主） |
| **地方管理空港** | 地方の小空港 | 都道府県・市町村 |

**コンセッション方式の拡大**（2010年代〜）

- 滑走路などのインフラは国/地方が所有したまま
- ターミナル運営を民間に委託（30〜45年長期）
- 仙台・熊本・広島・北海道7空港などで導入済み
- 民間の収益最大化（商業施設・駐車場）と利用料低減を両立

### 主な空港関連費用

| 費用 | 負担者 | 内容 |
|---|---|---|
| 着陸料 | 航空会社 | 機体重量・発着時間帯で変動 |
| 旅客ターミナル使用料 | 旅客（チケットに含む） | PFC（旅客施設使用料） |
| 航行援助施設利用料 | 航空会社 | ATC・VOR・ILS等の利用料 |
| 駐機料 | 航空会社 | 1時間あたり。深夜割増あり |
| 国際観光旅客税 | 旅客 | 日本発：1人1,000円 |

**羽田の着陸料**（目安）：B777クラスで約90〜150万円/回。深夜・早朝は割増。

## 8. 羽田の離発着数：フェルミ推定の検証

### ユーザーの推定

> 「滑走路が日本で3分おきに使われると仮定 → 1日600便近く」

### 実際のデータ

| 指標 | 数値 |
|---|---|
| 滑走路数 | **4本**（A・B・C・D滑走路） |
| 1日あたりの離着陸回数 | **約1,250〜1,300回** |
| 1時間あたりの最大処理能力 | **90回**（世界最高水準） |
| ピーク帯 | 朝7〜8時台・夕方17〜18時台 |

### フェルミ推定の整合性

```
ユーザー推定: 滑走路1本、3分に1便 → 20便/時 × 24h = 480便
実態: 滑走路4本 × 約20便/時（平均）× 24h × 稼働率 ≈ 1,200〜1,300回

→ 1本あたりに換算すると: 1,300 ÷ 4 = 325回/日 ≈ 約4.4分に1回
```

**推定はほぼ正確**。滑走路1本あたり3〜4分間隔という感覚は妥当。実際の混雑時は2分以下になることもある。

### 世界比較

羽田は**世界3位の混雑空港**（2023年実績）

1. アトランタ（ATL）：年間89万回超
2. シカゴ・オヘア（ORD）：88万回超
3. 羽田（HND）：約47万回
4. 成田（NRT）：約22万回

## 9. Skyscannerとダイナミックプライシング

### Skyscannerの仕組み

Skyscannerは**メタサーチエンジン**。自社では航空券を販売せず、裏側に複数の情報源を持つ。

```
Skyscannerユーザー
    ↓ 検索
Skyscannerエンジン
    ↓ 集約・比較
GDS（Global Distribution System）   ← 航空会社の座席在庫
  ├── Amadeus（欧州系）
  ├── Sabre（米国系）
  └── Travelport（Galileo/Worldspan）
OTA（Expedia, Booking等）
直販（航空会社公式サイト）
```

**GDS**は航空会社が座席在庫・価格をリアルタイムで配信するインフラ。ビジネスモデルはトランザクション課金（1予約あたり数ドル）。

### ダイナミックプライシングの仕組み

航空座席の価格最適化は**Revenue Management System（RMS）**が担う。

**基本原理：EMSR（Expected Marginal Seat Revenue）**

```
各座席クラスに「この価格で売れる確率」を計算
P(売れる) × 価格 = 期待収益を最大化するクラス配分を決定
```

**実際の変数（ライアンエアは20以上使用）**

| 変数 | 影響 |
|---|---|
| 出発日までの日数 | 近い日程ほど高い（ビジネス需要）or 安い（残席処理） |
| 搭乗率の推移 | 埋まりが早ければ早めに値上げ |
| 競合他社の価格 | スクレイピングで追随 |
| 曜日・時間帯 | 月曜朝・金曜夕は高い |
| 過去の需要実績 | 路線・季節ごとの統計モデル |
| イベント情報 | コンサート・学会・祝日 |

### 線形代数との関係

線形計画法（Linear Programming）がベースになっている部分がある。

- **最適化問題**：制約条件（座席数・クラス別在庫上限）のもとで総収益を最大化
- **需要予測**：回帰分析・機械学習（ランダムフォレスト・LSTMなど）
- **シミュレーション**：モンテカルロ法で将来需要の分布を推定

ただし現代のRMSはニューラルネットワークベースが主流になっており、古典的な線形計画は補助的役割。

### オーバーブッキングの数理

```
平均ノーショー率 × 座席数 = 追加販売可能枠を計算
ポアソン分布でノーショー人数の確率分布を推定
→ 補償コスト < 余剰販売収益 となる限界まで積み増す
```

## 10. 航空会社のPLで見るべき指標

### 特有の業界KPI

一般的なPLだけでは実態が読めない。以下の指標が必須。

#### キャパシティ・収益系

| 指標 | 計算式 | 意味 |
|---|---|---|
| **ASK**（Available Seat Kilometers） | 座席数 × 飛行距離 | 供給量の基本単位 |
| **RPK**（Revenue Passenger Kilometers） | 実搭乗者数 × 飛行距離 | 実需量 |
| **Load Factor** | RPK ÷ ASK | 座席利用率。80%超が黒字ライン目安 |
| **RASK**（Revenue per ASK） | 総収益 ÷ ASK | 1座席km当たりの収益力 |
| **Yield** | 旅客収益 ÷ RPK | 旅客1人が1km移動する単価 |

#### コスト系

| 指標 | 計算式 | 意味 |
|---|---|---|
| **CASK**（Cost per ASK） | 総費用 ÷ ASK | 1座席km当たりのコスト |
| **CASK ex-fuel** | （総費用−燃料費）÷ ASK | 燃料コスト除いた実力コスト |

**鉄則**：RASK > CASK なら黒字。ここを見るだけで勝ち負けがわかる。

#### 利益系

| 指標 | 意味 |
|---|---|
| **EBITDAR** | EBITDA + 航空機リース料。リースが資産でも費用でも比較可能にする |
| **Operating margin** | 営業利益率。5〜15%が健全圏 |
| **Ancillary revenue ratio** | アンシラリー比率。LCCは30〜40%、FSCは10%程度 |

#### PLを読むときの注意点

1. **燃料費の比率**：総コストの20〜30%が標準。高ければヘッジ状況も確認
2. **為替ヘッジ**：ドル建て費用（燃料・リース）に対して円安は直撃
3. **アンシラリーの成長性**：本業の収益性低下をカバーしているか
4. **負債/EBITDAR倍率**：3〜4倍以下が健全。航空は資本集約型で高めになりやすい

## 11. 機体の雑学

### A320ファミリー（エアバス）

- **初飛行**：1987年。世界初の**Fly-by-wire**（電気信号で操縦）民間機
- ナローボディ（1通路）の王者。B737と世界市場を二分
- A318/A319/A320/A321の4兄弟 + A320neo（新エンジン）
- **機体寿命**：約25〜30年、8万回の飛行サイクル
- LCCの主力機体（ライアンエア・IndiGo・AirAsia等）
- 乗客：150〜180人、航続距離：6,100km

### B747「ジャンボジェット」（ボーイング）

- **初飛行**：1968年。かつての「空の女王」
- 2階建て（上階はビジネスクラス・バーラウンジ）
- **4発エンジン**。当時は「2発では大西洋を越えられない」という規制があった（ETOPS規制）
- ピーク時は世界の長距離路線を独占
- 最終号機：2022年生産終了（ルフトハンザが受取）
- 貨物機（B747F）としてはまだ現役

### コンコルド（英仏共同開発）

- **初飛行**：1969年。**商業運航**：1976年〜2003年
- **最高速度**：マッハ2.04（音速の2倍）。ロンドン〜ニューヨーク 約3.5時間
- **乗客**：わずか100人。燃費は通常機の**5〜7倍**
- **チケット価格**：往復100万円超（ファーストクラス並み）
- **音速ブーム**：超音速飛行による衝撃波が地上に届く → 陸上での超音速飛行禁止
- **経済的失敗**：製造20機のみ。石油ショックで需要消滅
- **2000年墜落事故**（エールフランス4590便）が引導を渡す
- **教訓**：「技術的成功 × 経済的失敗」の象徴として航空史に残る

### B737 MAX（ボーイング）

- A320neoへの対抗として開発。重心バランスの問題を**MCAS（機動特性補正システム）**でソフト補正
- **2018・2019年に2度の墜落事故**（346名死亡）。MCASの欠陥が原因
- 2019年3月〜20ヶ月間の運航停止（史上最長）
- ボーイングは賠償・修正コストで**2兆円超**の損失

### B787「ドリームライナー」

- **複合材料革命**：機体の50%を炭素繊維強化プラスチック（CFRP）で製造
- アルミ製より軽く、**燃費20%向上**
- 機内気圧を高め（0.6気圧→0.83気圧）、乗客の疲労感軽減
- 窓が大きい（電気調光ガラス）
- **ANAが世界初導入**（2011年）

### A380（エアバス）

- **世界最大の旅客機**（総2階建て、最大853席）
- 4発エンジン、全幅80m
- 「ハブ空港集中型」時代に開発 → 格安直行便時代に合わず受注低迷
- **2021年生産終了**。ラストオーダーはエミレーツ航空のみ購入し続けた

## まとめ：航空産業の構造的本質

```
収益：コモディティ（価格競争で差別化困難）
費用：固定費の塊（燃料・人件費・リース）
リスク：外部ショックに無防備（テロ・感染症・原油）
参入障壁：規制・スロット・資本で「見かけ上高い」
実態：デフォルトリスクが常に高い、薄利多売産業
```

唯一の勝ち筋は**コスト最小化 × アンシラリー最大化**（LCCモデル）か、**ロイヤリティプログラムによる囲い込み**（大手FSCモデル）。
