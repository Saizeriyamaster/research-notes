# ダイヤモンド半導体エコシステム — Orbray / 大熊ダイヤモンドデバイス / EDP

**分析日:** 2026-06-24

---

## TL;DR

> 「究極の半導体素材」ダイヤモンドを巡り、**Orbray（材料製造）・大熊ダイヤモンドデバイス（量産工場）・EDP（種結晶・基板）** の3社が補完的なポジションで日本のダイヤモンド半導体産業を形成している。シリコン・SiC・GaNを超える性能特性を持つダイヤモンドは、廃炉・宇宙・防衛・次世代通信・EVパワーデバイス・量子コンピュータの全方位で需要が見込まれ、2028〜2030年の商用化が射程に入ってきた。


**主な取引先セグメント:**

| 量子/防衛（将来） | Element Six（英国）と提携し供給体制構築 |

### 競合優位性（Economic Moat）

| Moat類型 | 評価 | 根拠 |
|---------|------|------|
| 無形資産（特許・技術） | ○ | ダイヤモンドウェハ量産技術に固有の加工ノウハウ、光通信フェルールの超精密製造 |
| コスト優位 | △ | 国内唯一の光通信量産拠点、スケールは限定的 |
| スイッチングコスト | △ | 長期取引先への精密部品供給は切替が難しい |
| ネットワーク効果 | ✕ | 現段階では非該当 |
| 効率的規模 | ○ | ダイヤモンドウェハ量産で世界最大2インチを実現、希少性高い |

> **総合Moat評価: Narrow〜Wide（成長中）** — 現在は精密部品で安定的なNarrow Moat。ダイヤモンド半導体が本格普及すれば、ウェハ供給において Wide Moat に拡大する可能性。

### 最新技術トレンド（2025〜2026）

- **2025年3月:** 双晶のない最大20mm×20mmの(111)単結晶ダイヤモンド自立基板を開発、2026年内製品化予定
- **2025年:** Element Six（英国、世界最大人工ダイヤメーカー）と提携、ウェハスケール単結晶ダイヤの開発・供給体制
- **佐賀大との共同研究:** パワーデバイス 出力電力875MW/cm²・電圧2568V — ダイヤモンドとして世界最高性能
- **2インチウェハ量産 → 4インチ開発中:** 量子コンピュータ向けの高純度ダイヤモンドウェハ

## ③ 大熊ダイヤモンドデバイス（ODD）企業解剖

### 企業プロフィール

| 項目 | 内容 |
|------|------|
| 設立 | 2022年 |
| 出自 | 北海道大学・産業技術総合研究所（AIST）・日本原子力研究開発機構（JAEA）発スタートアップ |
| 本社 | 北海道札幌市 |
| 工場 | 福島県双葉郡大熊町（世界初ダイヤモンド半導体専用量産工場） |
| 竣工 | 2026年5月29日（竣工式） |
| 本格稼働予定 | 2028年度 |

### 大熊工場の意義

**世界初のダイヤモンド半導体専用製造拠点。**
- 最大年間数十万個の生産能力
- 2027年度中に生産装置搬入開始
- 地元採用積極推進（2026年度〜約20名、2028年度に40名超へ）

### ターゲット用途（最重要ポイント）

| 用途 | 詳細 |
|------|------|
| **原発廃炉** | 廃炉作業員の安全管理・原子炉内燃料デブリ検出に向けたダイヤモンド検出器。高放射線・300°C以上の過酷環境でも動作可能 |
| **宇宙** | 極限環境（-200°C〜+300°C）での耐久性 |
| **安全保障（防衛）** | 高出力・耐環境性を活かした素子 |
| **次世代通信（6G等）** | 高周波・高電力デバイス |

### なぜ「大熊町」か

- 福島第一原発事故後の復興エリア「福島イノベーション・コースト構想」の核心拠点
- 廃炉技術（ダイヤモンド検出器）と産業復興（半導体工場）を一体化
- 国・福島県・大熊町のバックアップが得られやすい立地

### 強み・リスク

| 強み | リスク |
|------|--------|
| 北大・産総研・JAEAの研究蓄積を商業化 | スタートアップのため量産立上げリスク |
| 「廃炉ユースケース」という希少・確実な需要 | ダイヤモンド加工は難難しく歩留まり管理が課題 |
| 国策（復興・半導体強化）に合致 | 2028年本格稼働まで収益化に時間 |
| 世界初の量産工場という象徴性 | 競合（Element Six等）の海外大手が追随 |

## ⑥ ダイヤモンド半導体の技術的優位性（なぜ「究極」か）

| 特性 | Si（シリコン） | SiC | GaN | **ダイヤモンド** |
|------|-------------|-----|-----|---------------|
| バンドギャップ | 1.1 eV | 3.3 eV | 3.4 eV | **5.5 eV** |
| 熱伝導率 | 低 | 高 | 中 | **極めて高い（20× Si）** |
| 絶縁破壊電界 | 低 | 高 | 高 | **最高** |
| 動作温度 | ~150°C | ~300°C | ~200°C | **500°C以上** |
| 放射線耐性 | 低 | 中 | 中 | **最高** |

> **理論上の性能上限はSiCの30倍以上。** 廃炉・宇宙・防衛などの「特殊環境需要」から先に市場が立ち上がり、EVパワーデバイス・量子コンピュータへと広がる構造。

## ⑧ 強み・リスク・成長ドライバー

### 日本勢 全体の強み

| 強み | リスク |
|------|--------|
| 廃炉ユースケースという確実な需要（唯一無二） | ダイヤモンド加工の難しさ（コスト・歩留まり） |
| 国策（復興・半導体強化）の追い風 | 2030年代まで大市場化まで長い時間 |
| 北大・産総研・佐賀大など強固な研究基盤 | Element Sixなど海外大手のキャッチアップ |
| Orbray×大熊DD×EDPの役割分担が明確 | スタートアップの資金調達リスク |

### 成長ドライバー 3つ

1. **廃炉需要の確実性** — 東電福島第一の廃炉は数十年にわたるプロジェクト。放射線耐性を持つダイヤモンド検出器は代替不能な需要。
2. **量子コンピュータ市場** — NVセンターをダイヤモンド内に形成することで量子ビットを実現。Orbrayの高純度ウェハが基盤材料に。
3. **EV・次世代パワー半導体** — SiCの10〜30倍の性能でEV駆動系の革命が可能。トヨタ・デンソー連合が2030年代商用化を本気で狙う。
