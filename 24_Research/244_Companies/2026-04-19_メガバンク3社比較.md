## 1. 沿革・合併史

### 三菱UFJフィナンシャル・グループ（MUFG）

| 年月 | 出来事 |
|---|---|
| 1880年 | 三菱為換店設立（三菱銀行の源流） |
| 1880年 | 横浜正金銀行設立（東京銀行の源流） |
| 1919年 | 三菱銀行 正式設立 |
| 1946年 | 横浜正金銀行 → **東京銀行**に改称 |
| 1996年 | 三菱銀行 × 東京銀行 → **東京三菱銀行**誕生 |
| 2001年4月 | 東京三菱銀行・三菱信託銀行・日本信託銀行が株式移転 → **三菱東京フィナンシャル・グループ（MTFG）** |
| 2001年4月 | 三和銀行・東海銀行・東洋信託銀行が株式移転 → **UFJホールディングス** |
| 2002年1月 | 三和銀行 × 東海銀行 → **UFJ銀行**誕生 |
| 2005年10月 | MTFGがUFJホールディングスを合併 → **MUFG発足**（総資産約190兆円・世界最大級） |
| 2006年1月 | 東京三菱銀行 × UFJ銀行 → **三菱東京UFJ銀行** |
| 2018年4月 | **三菱UFJ銀行**に改称 |

**MUFGの源流まとめ：** 三菱系（三菱銀行）＋旧横浜正金（東京銀行）＋三和系（UFJホールディングス）の大合流

### 三井住友フィナンシャルグループ（SMFG）

| 年月 | 出来事 |
|---|---|
| 1876年 | 三井銀行設立 |
| 1895年 | 住友銀行設立 |
| 1990年 | 三井銀行 × 太陽神戸銀行 → **太陽神戸三井銀行**（都銀2位規模） |
| 1992年 | **さくら銀行**に改称 |
| 1999年10月 | 住友銀行 × さくら銀行、全面統合合意 |
| 2001年4月 | 住友銀行 × さくら銀行 → **三井住友銀行**誕生 |
| 2002年12月 | 三井住友銀行・日本総研・三井住友カードが株式移転 → **SMFG設立** |
| 近年 | SMBCカード・ファイナンスサービス統合、SMBCコンシューマーファイナンス子会社化など継続再編 |

**SMFGの源流まとめ：** 三井系（三井銀行→さくら銀行）＋住友系（住友銀行）の2大財閥合流

### みずほフィナンシャルグループ

| 年月 | 出来事 |
|---|---|
| 1873年 | 第一国立銀行設立（後の第一勧業銀行） |
| 1880年 | 安田銀行設立（後の富士銀行の源流） |
| 1902年 | 日本興業銀行（長期信用銀行）設立 |
| 1971年 | 第一銀行 × 日本勧業銀行 → **第一勧業銀行** |
| 1999年8月 | 第一勧業銀行・富士銀行・日本興業銀行の頭取3名が統合発表（総資産140兆円・世界最大構想） |
| 2000年9月 | 株式移転 → **みずほホールディングス**設立 |
| 2002年4月 | **みずほ銀行**（個人・中小企業）と**みずほコーポレート銀行**（大企業）に分割 |
| **2002年4月** | **大規模システム障害**（振込遅延・ATM停止）発生 → 社会問題化 |
| 2003年1月 | **みずほフィナンシャルグループ**設立 |
| 2013年7月 | みずほコーポレート銀行がみずほ銀行を吸収 → **みずほ銀行**に一本化 |
| 2021年 | システム障害が複数回再発、金融庁から業務改善命令 |
| 2026年4月（予定） | みずほ銀行 × みずほリサーチ&テクノロジーズ統合検討中 |

**みずほの源流まとめ：** 3大系列の混合（旧第一勧業＝旧財閥系）＋富士銀行（安田財閥）＋興業銀行（政策系）。3文化の融合コストが今も組織に残る。

## 3. 競合優位性とキャラの違い

### MUFG — 「グローバルエリート」

**強み:**
- 海外利益比率が約45%で3行中最もグローバル展開。タイのアユタヤ銀行・米モルガンスタンレーとの提携が象徴的
- 純利益1.86兆円で独走状態（みずほの約2倍）
- 国内最大の時価総額（約32兆円）・世界13位

**カルチャー:**
- 「三菱ブランドへの信頼感・エリート意識・安定感」
- インテリ集団イメージが強い
- 大企業・グローバル取引に強く、個人リテールはやや地味

---

### SMFG — 「デジタルリテール革命」

**強み:**
- Oliveを軸にしたリテール革命で若年層獲得に成功
- 東南アジアへの積極出資（インドネシア・ベトナム等）
- 個人預金・カード会員数の成長率が3行中最高
- 三井住友カード・SMBCグループの強力な決済インフラ

**カルチャー:**
- 「体育会系・営業ノルマ強め」だが自由度もある
- リテール（個人）ビジネスへの執念が際立つ
- Oliveに見られるようなプロダクト思考が近年強化

---

### みずほFG — 「法人特化・調整型」

**強み:**
- 国内上場企業の約7割と取引する法人顧客網
- 2,400万口座の個人基盤
- 全47都道府県に支店を持つ唯一のメガバンク（地方カバー力）
- IT基盤再構築に4,800億円を投じ、過去障害から脱却図る

**カルチャー:**
- 「穏やか・特色なし・人情経営」
- 3行統合の調整コストが組織文化に今も残る
- 「みずほらしさ」を打ち出しにくい体質

## 4. Olive（三井住友）のビジネスモデル

### 概要
2023年3月ローンチ。**「1枚のカードで4つの機能」**が世界初の発明。
- キャッシュカード / クレジット / デビット / Vポイント払い を1枚に集約

### ユーザー規模・収益
| 指標 | 数値 |
|---|---|
| アカウント数（2026年3月） | **700万件**（黒字化達成済み） |
| 2027年度末目標 | **1,200万件** |
| Olive効果による個人預金増 | **1.6兆円増** |
| 2028年度収益貢献目標 | **800億円** |

### ポイント経済圏
- **Vポイント**（旧Tポイントと統合）を核としたエコシステム
- **PayPayとの相互交換**で延べ**3億8,000万人規模**の経済圏を形成
- SBI証券との連携（SMBCグループ）でインベストメント誘導

### 収益モデル
1. 加盟店手数料（クレジット決済）
2. 個人預金増によるスプレッド収益
3. 証券・ローン・保険への誘導収益
4. データ活用による行動ターゲティング広告（将来）

### なぜ強いか
- **若年層（20代以下が半数）**を取り込んでいる → 長期LTV高
- PayPayという国内最大の決済プラットフォームとの連携が強力な差別化
- 「銀行口座×クレカ×ポイント」を一気通貫で設計した唯一の商品

## 5. えむっと（MUFG）のビジネスモデル

### 概要
**2025年6月2日始動。** 三菱UFJ銀行アプリのリニューアル版で、銀行・カード・証券・ロボアドを統合したスーパーアプリ構想。

### 特徴
- 対象店舗で通常**7%**、最大**20%**のグローバルポイント還元
- **2026年度「エムットポイント」（グループ共通ハウスポイント）を導入予定**
- 同時にロイヤリティプログラム・デジタルバンク開業も予定

### Oliveとの差
- Oliveに対して**約2年遅れ**のスタート
- ポイントの使い出・経済圏の広がり・UXでOliveに劣後
- MUFGの潜在顧客基盤（口座数・法人取引先数）は最大だが、個人リテールで動員できていない

## 6. ポイント経済圏：Oliveの圧勝か？

### 現在地

```
Olive（SMFG）  ████████████████████ 圧倒的先行
えむっと（MUFG） ██████░░░░░░░░░░░░ 2026年度が正念場
みずほ         ████░░░░░░░░░░░░░░ 楽天/PayPay依存・自前設計力なし
```

### Oliveが圧勝している理由

1. **先行者優位の定着**: 700万件アカウント・黒字化達成
2. **PayPay連携（3億8,000万人エコシステム）**: スケールが別次元
3. **若年層キャプチャー**: 20代以下が半数 → 40年以上のLTV
4. **フレキシブルペイの革新性**: 競合が追いつきにくい設計

### えむっとの反撃シナリオ

- MUFGは**日本最多の口座保有者**と**グローバル企業取引**が武器
- 2026年エムットポイント導入後、法人従業員向け福利厚生連携で一気に動員する可能性
- ただし**スマホUX・ブランドの若さ**でOliveとの差は大きい

### みずほの戦略

- **楽天経済圏（1億ユーザー）・dポイント・PayPay**への交換対応で弱点を補う外部依存型
- 自前経済圏設計力なし → 「みずほ色」が薄い
- 2025年4月の「みずほポイントモール」開設は前進だが主導権は相手側
