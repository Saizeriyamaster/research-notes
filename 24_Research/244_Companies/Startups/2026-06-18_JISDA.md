## TL;DR

「7万円で作り、撃って、使い捨てる」── ウクライナ前線で3年間過ごした創業者が辿り着いた、防衛ドローンの逆張り思想。高コスト・少数精鋭型の日本防衛産業に対し、"完全国産・低コスト・消耗前提"という全く逆のドクトリンを持ち込む。2025年11月設立の超早期スタートアップだが、Shiraha（白羽）ドローンのナラティブは突き刺さる。公開調達実績は限定的だが、防衛装備庁がデュアルユーススタートアップとして注目し、RISEコンソーシアムを通じた産学官連携で足場を固めている。

### 旗艦プロダクト: ACM-01「Shiraha（白羽）」

> 「高価な機体を限られた場面で使う発想から脱却する」

| 仕様 | 内容 |
|------|------|
| 機体タイプ | 固定翼ドローン（訓練・短距離作戦用） |
| 翼幅 | 1.9m |
| 原価 | **7万円（約$450）** |
| 素材 | 木製フレーム（発泡樹脂翼も開発中） |
| 製造 | **完全国産**（部品含め全て国内製造） |
| 技術特徴 | 壊れる前提の設計。修理・補充・訓練をパッケージ化 |
| 公式認定 | 目視外飛行（BVLOS）試験成功 |

**「Skill House」パッケージ:**
Shirahaは単体販売ではなく、以下をバンドルした**サービス型防衛商品**として提供:
- 機体在庫管理
- 修理・補充サービス
- 実践的飛行訓練

これにより、「機体を売る」ではなく「訓練能力を売る」モデルに転換しており、継続収益（ARR的な性質）が生まれる。

**開発背景（最重要）:**
創業チームはウクライナ前線から約**20km地点**で3年間にわたり実地調査。"消耗品としてのドローン"という戦場の現実を直接見た上で設計哲学を決定した。

## ④ RISEコンソーシアム（2026年3月設立）

**RISE: Resilient Initiative for Unmanned Systems Engineering**

JISDAが主導する産学官の無人アセット横断コンソーシアム。

| 項目 | 内容 |
|------|------|
| 設立 | 2026年3月 |
| 参加組織数 | 10社以上（企業・自治体・大学・研究機関・シンクタンク） |
| 主要参加企業 | 日本海洋重工業（USV/AUV）、MadeHere（3Dプリント製造） |
| 目標 | ①モジュラー型無人機、②国内スマート分散製造、③スウォーム制御技術 |
| 意義 | "単製品"から"継続的アップデートフレームワーク"への競争軸転換 |

RISEはJISDAを単なるドローンメーカーではなく、日本の無人アセット産業の**エコシステムオーケストレーター**として位置づけるための戦略的布石。

## ⑥ バリュエーションナラティブ分析（7条件）

Traysarとは異なる「日本型防衛テック」のナラティブとして分析する。

### 条件① 新パラダイム性 ── "This time is different"

> **「ウクライナが証明した：防衛ドローンは"高価な宝物"ではなく"大量消耗品"だ」**

日本の防衛産業は長年、「精密・高価・少数」のドクトリンで動いてきた。JISDAはそれを根底から否定する:

- 従来の思想：1機数百万円〜億円のドローンを大切に使う
- JISDAの思想：7万円のドローンを大量に訓練で壊し、戦場で使い捨てる

ウクライナ戦争が世界中に見せた"消耗戦の現実"が、このパラダイムシフトの正当性を担保している。防衛省・自衛隊の調達部門にとって、従来の評価尺度（機体性能・耐久年数）が「訓練コスト・補充速度」という新軸に置き換えられる。

**スコア: ★★★★☆** ── 日本防衛産業への逆張りは鮮明だが、海外では既に常識化しているためグローバル文脈では新奇性がやや落ちる

---

### 条件② 青天井感 ── 市場上限が見えない

> **「防衛費GDP比2%化で55億ドル→120億ドルへ拡大。だが自衛隊はまだほとんど訓練できていない」**

| 指標 | 内容 |
|------|------|
| 日本防衛予算 | 2025年度 約5.5兆円（過去最大）、2027年目標でGDP比2% |
| 無人機調達需要 | 自衛隊の無人化・スウォーム化は政策的優先課題 |
| 訓練不足の構造 | 機体が高いから訓練できない → 訓練量が増えない悪循環 |
| Shiraha需要試算 | 訓練量3倍化だけで数千機/年の需要が潜在的に存在 |

さらに、同盟国（米・英・濠）への輸出解禁（防衛装備移転三原則の緩和）が進み、国際市場への扉が開きつつある。

**スコア: ★★★★☆** ── 防衛予算拡大は確実。ただし防衛省の調達スピードの遅さがボトルネックになる変数

---

### 条件③ 希少性 ── このチームにしかできない

> **「ウクライナ前線20kmで3年過ごした創業者が、日本唯一の"完全国産"防衛ドローンを作る」**

| 希少性の軸 | 内容 |
|-----------|------|
| 実地知見 | ウクライナ前線付近での3年間の現場調査は、日本の防衛テック創業者として圧倒的に希少 |
| 完全国産の意志 | 安全保障上、DJI排除・外国依存排除を求める調達側ニーズに100%合致 |
| 政策文書掲載 | 防衛装備庁・経産省の公式報告書（2024年9月）に名指しで言及された唯一の超初期段階スタートアップ |
| 事業多角性 | ドローン×サイバー×防衛医学の三角形は、純粋ドローンスタートアップにはない安全保障の深さ |

**スコア: ★★★★★** ── ウクライナ前線調査3年＋完全国産＋政府公認の組み合わせは国内に他にない

### 条件⑦ 再帰性 ── 自己強化ループ

```
低コストドローン（7万円）の供給
        ↓
自衛隊・民間の訓練量が飛躍的に増加（今まで壊せなかった）
        ↓
大量の訓練データ・運用ドクトリンの蓄積（JISDAが独占）
        ↓
Skill Houseの継続課金（訓練パッケージ）で収益安定化
        ↓
防衛省との関係深化 → 次世代機の共同開発・調達
        ↓
RISEコンソーシアムを通じた産業標準の形成
        ↓
完全国産・低コストの「日本標準ドローン」になる
        ↓ (ループ)
海外同盟国（米・英・濠・ウクライナ）への輸出展開
```

特に重要なのは「訓練データの独占」。Skill Houseによって自衛隊の訓練データがJISDAに蓄積され、次世代機開発や運用ドクトリン設計においてロックインが生まれる。

**スコア: ★★★★☆** ── 訓練データ→ドクトリン設計→標準化のループは強力。ただしスタートアップの組織力が問われる

## ⑦ 強み・リスク・成長ドライバー

| 強み | リスク |
|------|-------|
| 完全国産（DJI排除の唯一の訓練用代替） | 防衛省調達プロセスの長期化・官僚的障壁 |
| ウクライナ現地3年調査の実証的裏付け | 超初期段階であり組織的スケールが未証明 |
| 7万円という強力な価格アンカーと訴求力 | ACSL等の上場大手が同セグメントに本格参入する可能性 |
| RISEコンソーシアムによるエコシステム形成 | 資金調達状況が不透明でランウェイリスク |
| Skill Houseによる継続収益モデル | 防衛装備移転三原則の規制変化に依存する輸出戦略 |

**3つの成長ドライバー:**
1. **防衛費倍増×無人化政策** — 自衛隊の無人アセット導入は政府の最優先課題。JISDAはその入口にいる
2. **DJI排除トレンドの恩恵** — 中国製ドローン締め出しにより、完全国産の選択肢はJISDAが唯一に近い
3. **輸出解禁×同盟国需要** — 防衛装備移転の規制緩和で、ウクライナ・NATO・豪州向け輸出が現実的な選択肢に
