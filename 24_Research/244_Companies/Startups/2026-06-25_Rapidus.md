# Rapidus（ラピダス）

> 日本の"半導体復権"を賭けた国家プロジェクト型スタートアップ。2nm世代ロジック半導体の量産を2027年に目指す。

---

## TL;DR

日本の半導体シェアが1980年代の50%から激減した反省から、2022年に日本政府と国内大手8社が共同で設立。IBMから2nm技術をライセンスし、北海道・千歳に工場（IIM-1）を建設中。現在は開発フェーズで、商業収益はほぼゼロ。政府補助金で運営しており、2027年量産・2031年上場を目標とする。

## 2. 財務（開発フェーズのため要注意）

> 現時点で"売上"として計上されているのは、ほぼ**政府補助金の受領額**。商業ベースの顧客売上は実質ゼロ。

| 期 | 売上相当（補助金含む） | 損益 |
|----|----------------------|------|
| 2024年12月期 | 約829億円 | 営業損失 約2.9億円 |
| 2025年12月期 | 約1,474億円 | 純損失 約37.5億円 |

**政府支援額（累計）：**
- 経済産業省補助金（2025年度）：8,025億円
- 追加支援（2024年4月決定）：6,315億円
- 民間合計：約1.3兆円（2025年時点）

**総調達額は数兆円規模**に達する見通し。TSMCが台湾政府に数十年かけて蓄積したものを、日本は5〜10年で追いつこうとしている。

## 4. 設立の経緯・背景

### 日本半導体の栄光と凋落

```
1980年代：日本の世界シェア 約50%（NEC・富士通・日立・東芝）
   ↓
1986年：日米半導体協定 → 日本に輸出数量規制・市場開放義務
   ↓
1990年代：韓国（Samsung・SK Hynix）・台湾（TSMC）の台頭
   ↓
2000年代〜：日本は成熟プロセス（レガシー半導体）専門に後退
   ↓
2020年代：AI・自動車・安全保障で先端半導体が地政学上の"戦略物資"に
```

### Rapidus誕生の直接的トリガー（2022年）
1. **米中半導体戦争**：米国によるHuaweiへの輸出規制で「半導体＝安保」と世界が認識
2. **CHIPS法（米）**：米国が自国内での半導体製造に500億ドルを投入
3. **日米首脳会談（2022年7月）**：次世代半導体での協力を合意
4. **岸田首相演説**：「日米連携で2nm半導体を国内量産する」と宣言
5. **同年8月**：Rapidus設立

## 5. 技術：2nmとは何か？

### トランジスタ構造の革命：FinFET → GAA

```
【従来（〜3nm）: FinFET】
     ゲート
      ↓
  ┌──┐ ┌──┐
  │フィン│  （縦に立ったシリコンの「ひれ」）
  └──┘ └──┘
  → ゲートが3面を囲む

【2nm〜: GAA（ゲート・オール・アラウンド）ナノシート】
    ────────── ゲート
   ┌──────────┐  ← シリコン薄板（ナノシート）
    ──────────
   ┌──────────┐  ← 複数枚積層
    ──────────
  → ゲートが4面すべてを囲む（完全包囲）
```

**GAAのメリット：**
- 電流のリーク（漏れ電力）を大幅削減
- 同じ面積でより多くのトランジスタを配置可能
- ナノシートの幅を変えることで性能・省電力を柔軟にチューニング可能

### 3nmと比べた性能向上（TSMC N2実績）

| 指標 | 向上幅 |
|------|--------|
| 消費電力 | 同性能で最大 **▲30%** |
| 処理速度 | 同電力で最大 **+15%** |
| トランジスタ密度 | 約 **1.15倍** |

## 6. Rapidusの技術的アプローチ

### IBMからの技術ライセンス
- IBMが2021年に**世界初の2nm試作チップ**を発表（Albany NanoTech）
- Rapidusはそのプロセス技術をライセンス取得
- 約150名のエンジニアを2年間 Albany に派遣・共同開発

### EUV（極紫外線）リソグラフィ
- 2024年12月：ASMLのEUV露光装置を千歳IIM-1に搬入・設置
- 2nmパターン形成に必須の設備（1台100〜200億円）

### マイルストーン
| 日付 | 出来事 |
|------|--------|
| 2022年8月 | 設立 |
| 2023年 | IBM提携・千歳IIM-1建設開始 |
| 2024年12月 | EUV装置設置・フルオートパターン露光成功 |
| **2025年7月18日** | **2nm GAA トランジスタの電気的動作確認（世界最先端）** |
| 2026年3月（目標） | 顧客向けサンプル提供 |
| 2027年後半（目標） | 量産開始（月産数万枚規模） |
| 2031年（目標） | IPO |

## 8. 技術的実現可能性の評価

### 「2nm自体」は実現可能か？ → **YES、すでに実証済み**
- TSMCが2025年に**N2（2nm世代）量産を開始**（歩留まり約70%）
- Rapidusも2025年7月に2nm GAAトランジスタの動作を確認
- 技術的には「できる」ことが証明された

### 「Rapidusが2027年に量産」は実現可能か？ → **不透明、リスク大**

**課題：**
1. **歩留まり（Yield）**：TSMCは数十年の製造ノウハウ。Rapidusはゼロから立ち上げ
2. **人材不足**：先端プロセスを扱えるエンジニアが国内にほぼいない
3. **装置調達**：EUV装置はASML独占、入手競争が激化
4. **資金**：量産には追加で数兆円が必要とされ、民間資金調達の見通しは不透明
5. **顧客開拓**：2027年時点でTSMCは1.5nm/1nmを量産予定 → 競争が激化

**楽観シナリオ**：政府支援継続・AI需要爆発・Tenstorrentを足がかりに北米顧客獲得
**悲観シナリオ**：歩留まり向上に失敗・資金不足・顧客が大手に流れる

## 9. ナラティブ評価（バリュエーション7条件）

| 条件 | 評価 | コメント |
|------|------|---------|
| 新パラダイム性 | ◎ | 2nm GAA・日本国産量産は前例なし |
| 青天井感 | ◎ | AI・自動車・安保の半導体需要は無限 |
| 希少性 | ◎ | 量産できる国はTSMC・Intel・Samsungのみ（現状） |
| 権威の裏書き | ◎ | 政府・IBM・トヨタ・ソニーが全力支援 |
| 一文での伝染性 | ○ | 「日本の半導体復権」は刺さるが、技術的詳細は難解 |
| 指数化できる指標 | △ | 歩留まり・量産開始日・受注額が未開示 |
| 再帰性 | △ | まだ量産前。成功すれば投資→顧客→技術の好循環へ |

**総評：** ナラティブとしては強力。現実は開発フェーズで商業価値はこれから。2027年量産の成否がすべての分岐点。
