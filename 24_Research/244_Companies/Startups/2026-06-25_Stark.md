# Stark Defence — スタートアップ解剖

**分析日:** 2026-06-25

## TL;DR
ウクライナの戦場から学んだ「AIドローンが兵士の命を救う」という命題を、欧州防衛の政治的空白と€800Bの再軍備予算に刺さるナラティブに変換することで、創業2年で€3.5B評価額に達したドイツ防衛テックスタートアップ。米依存からの欧州防衛自立という大義と、SequoiaとFounders Fundという「相反する」投資家の同席が、ナラティブの信頼性と市場性を同時に証明している。

## 事業領域・プロダクト

### 旗艦プロダクト/サービス

| 項目 | 内容 |
|------|------|
| プロダクト名 | OWE-V Virtus（One-Way Effector、VTOL型） |
| 概要 | 垂直離着陸型ローター式攻撃ドローン。自律的に標的を識別・追尾し、体当たり攻撃で自爆 |
| 飛行性能 | 射程100km、急降下速度250km/h、搭載弾頭5kg |
| 技術的特徴 | オンボードAI（標的識別・自律航法）、X字翼設計、GPSなし環境でも動作可能 |
| 収益モデル | ハードウェア直販（政府/軍）＋ソフトウェア（Minervaミッション管理）のサブスクリプション |

### 2026年6月新製品（ILA Berlin）
- **Cascade**: チューブ発射型、射程100km、大量投射向け
- **Gambit**: 人携帯可能クアッドコプター（ISR＋近距離攻撃）

## 強み・リスク・成長ドライバー

| 強み (Strengths) | リスク (Risks) |
|-----------------|--------------|
| ウクライナ実戦フィードバックによる継続的製品進化 | 2025年の軍事試験で4回中4回失敗という報告（信頼性リスク） |
| Bundeswehr €268M契約という政府調達の実績 | Florian Seibel（創業の象徴）がCEO退任、ブランド人格の希薄化 |
| Sequoia+Thiel+NATO Fundという「権威の三角形」 | 欧州防衛調達の政治的変動リスク（和平交渉→予算縮小） |
| 欧州・NATO圏内に完結したサプライチェーン | 量産スケールの未実証。軍が必要とする「数万基」の製造能力は未確認 |
| VerticallyIntegratedモデル（HW+SWの複合収益） | 競合Helsing（$18B）、Anduril（$61B）との評価額格差 |

**3つの成長ドライバー:**
1. **ReArm Europeの支出加速** — EU€800B、独GDP2%超防衛費が既定路線。Starkはその受け皿として最もポジショニングが整っている
2. **消耗品ビジネスモデルへの移行** — Virtus/Cascade/Gambitが「撃てば補充する」弾薬モデルに近い消耗品特性を持ち、継続的な政府購入が見込める
3. **ウクライナへの製造拠点移転** — スタークはウクライナでの完全サイクル製造拠点設立を発表。「現地生産によるコスト削減」と「戦場フィードバック直結」の二重効果
