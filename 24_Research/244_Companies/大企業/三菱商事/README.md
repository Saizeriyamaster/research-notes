# 三菱商事 リサーチ

三菱商事に関するリサーチをここにまとめる。

## フォルダ構成
- `財務/` — IR資料・決算・株価関連
- `ビジネス/` — 事業・プロジェクト・事例（地域が明確なものは`地域/`へ）
- `歴史/` — 沿革・過去の出来事
- `経営陣/` — 役員・組織
- `子会社/` — 子会社・関連会社
- `地域/` — 大陸・地域別のプロジェクトと歴史的接点（オーストラリア／北米／アフリカ／中東／アジア／欧州／中南米）
- `その他/` — Notion・転送メッセージなど未分類の社内メモ

Slackスレッド（https://wanderlust8848.slack.com/archives/C07A4NVV465/p1782309076066949）で共有されたリンクを上記フォルダに一次転記済み。追加のリサーチはこのフォルダ配下に随時追加していく。
