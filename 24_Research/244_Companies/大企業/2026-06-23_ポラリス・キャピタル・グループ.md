# ポラリス・キャピタル・グループ — CoAnal 企業解剖

**分析日:** 2026-06-23

---

## TL;DR

「日本型バイアウトの独立系旗手」。みずほ系金融機関の出資で2004年に産声を上げ、オーナー事業承継・大企業カーブアウト・MBOの3本柱で約48件・累計3,500億円超の投資実績を積み上げてきた国内屈指の中堅PE。近年は生成AIスタートアップ（ストックマーク）への過半数取得など"グロースバイアウト"に踏み出し、テック領域へ戦略の射程を広げている。

## ストックマーク取得の詳細

### 概要
- **取引発表:** 2024年10月21日
- **調達額（第三者割当増資）:** 45億円（シリーズD）
- **取得形態:** 第三者割当増資の引き受け＋既存株主保有株式の一部取得の組み合わせ
- **取得株式比率:** **過半数（50%超）** ← ポラリスの公表ベース。具体的な%は非開示
- **累計調達額:** シリーズA〜DおよびDebt合計で88億円超
- **FA（財務アドバイザー）:** Project Coalis（コアリス）

### なぜストックマークを買ったか

| 理由 | 詳細 |
|------|------|
| グロースバイアウト適合 | Anews SaaSの売上高10億円超・高水準のARR成長。収益の予見性とスケーラビリティがポラリスのGrowth Buyoutコンセプトに合致 |
| 技術優位性 | 自社開発LLMを基盤とする独自AI基盤。エンタープライズ向け生成AIプラットフォームで差別化 |
| 新規事業「SAT」の成長ポテンシャル | Anews以外にSAT（Stockmark AI Transformation）という第二のエンジン育成中 |
| 強固なチームと組織 | 創業者・浅田慎二CEOのリーダーシップと技術チームを高く評価 |
| 資金用途の明確性 | プロダクト強化・LLM開発・M&A・海外展開という明確な成長ロードマップ |

## 投資スタイル

### 基本コンセプト

**「創業者精神の解放」型バイアウト** — 制約から経営を解き放ち、ビジネスモデル革新を促す。

### 3大ディールタイプ

| タイプ | 内容 | 比率（推定） |
|--------|------|------------|
| オーナー事業承継 | 創業者・オーナーからの経営権引き継ぎ | 高 |
| 大企業カーブアウト | 大企業が非中核事業と位置づける子会社・事業部の切り出し | 高 |
| 非公開化（MBO） | 上場企業のTOBによる上場廃止＋経営陣との共同 | 中 |
| 他ファンドからのセカンダリー | 他PE保有株の引き継ぎ | 低〜中 |
| **（新）グロースバイアウト** | 高成長SaaS・テック企業の過半数取得 | 拡大中 |

### ターゲットセクター

1. **テクノロジー・製造** — グローバルに通用する技術・特許を持つ企業
2. **ヘルスケア・医療・介護** — 高齢化対応・ESG視点の社会インフラ
3. **IT・サービス・物流** — デジタル化で新たな価値を生む成長企業
4. **消費財・小売** — 国内強固ブランドの海外展開ポテンシャル

### バリューアップ手法

- **投資後100日プログラム:** GP社員を投資先に常駐させ集中支援
- **DX推進・業務効率化**
- **アドオン買収（M&A）による規模拡大**
- **海外展開支援**
- **再上場（IPO）または戦略的売却**で3〜5年後にイグジット

## 強み・リスク

| 強み | リスク |
|------|--------|
| 国内独立系PEとして最大級のAUM（3,500億円超） | LP開示なし→資金調達基盤の可視性が低い |
| 創業者精神解放×100日プログラムの独自バリューアップ哲学 | 投資先の業績悪化リスク（外食・製造等景気敏感） |
| 金融系出身（みずほ興銀）の信用力・ネットワーク | テック系（グロースバイアウト）は既存バイアウトとは異なる評価スキルが必要 |
| 京都大学経営管理大学院との寄附講座設置（学術連携） | 国内限定で為替・地政学リスクは限定的だが成長天井も国内市場依存 |
| 3〜5年の明確なイグジット志向でLP還元実績あり | ストックマーク等AIスタートアップはイグジット時の評価変動大 |
