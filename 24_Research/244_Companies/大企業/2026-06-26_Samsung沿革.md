## 1. 設立前夜：李秉喆と「三星」の誕生（1938年）

### 1.1 創業

1938年3月1日、李秉喆（イ・ビョンチョル、Lee Byung-chul）は朝鮮総督府統治下の大邱（テグ）で「三星商会（サムスン商会）」を設立した。従業員40名、扱い品目は乾魚・農産物・麺類など地元産品の取引と運輸・不動産業。

「サムスン（三星）」とは「三つの星」を意味し、「空に輝く星のように——大きく、力強く、永遠に輝く」という李の企業ビジョンを象徴する。

### 1.2 戦後の多角化（1945〜1960年代）

| 年 | 出来事 |
|---|---|
| 1945 | 朝鮮独立後、ソウルに本社移転 |
| 1950年代 | 製糖・毛織物・保険・流通へ多角化。朝鮮戦争後の復興需要を取り込む |
| 1953 | 第一製糖（現CJ）設立。食品産業へ |
| 1954 | 第一毛織設立（現サムスンSDI） |
| 1963〜 | 政府の産業近代化政策と連動し、銀行・百貨店・ホテルへ拡大 |

## 2. 電子・半導体事業への参入（1960〜1974年）

### 2.1 電子産業への参入（1969年）

1960年代後半、韓国政府が電子産業育成を国策化したことを受け、サムスンは電子事業に進出した。

- **1969年**: サムスン電子工業（後のサムスン電子）設立、水原市に工場開設
- 日本の三洋電機と合弁（サムスン三洋電機）を結成。テレビ・冷蔵庫・洗濯機の生産開始
- 初期の製品は設計・技術ともに日本からの技術移転依存

### 2.2 半導体事業の取得（1974年）

1974年、サムスングループは経営危機に瀕していた**韓国半導体（Korea Semiconductor）**を買収。これがサムスン半導体事業の原点となる。

- Korea Semiconductorは韓国初の半導体製造設備を建設中だったが資金難
- 李秉喆の長男・李孟煕の個人的な投資として買収（グループ承認なしの先行投資）
- 当初は時計用ICなど単純な製品しか作れなかったが、後の半導体帝国の礎となった

## 3. 韓国の政治状況と財閥政策

### 3.1 朴正熙政権（1963〜1979年）：財閥育成の時代

サムスンが大企業に成長した背景には、朴正熙政権の**輸出主導型工業化戦略（開発独裁）**との蜜月関係があった。

| 政策 | 内容 |
|---|---|
| 輸出産業優遇 | 外貨獲得企業への融資優遇・税制優遇 |
| 財閥保護 | 外資との競合から国内財閥を保護する参入規制 |
| 政府系銀行による融資 | 市場金利以下での政策金融。財閥は「選択と集中」が可能に |
| 電子産業育成 | 1969年「電子工業振興法」制定。外資誘致と国内育成を並立 |

サムスンは政府の「財閥を育ててナショナルチャンピオンを作る」という戦略の最大受益者の一つとなった。

### 3.2 全斗煥政権（1980〜1987年）：半導体国策化

1979年の朴正熙暗殺後、光州事件（1980年）を経て実権を握った全斗煥政権は、半導体を**「21世紀の戦略産業」**と位置づけた。

- **1982年**: 政府の「半導体工業育成計画」策定。DRAM開発を国家目標に
- 大企業（サムスン・現代・LG等）に対し、政府が**低利融資・R&D補助・輸入規制**を組み合わせた支援を実施
- **1983年**: サムスンが「東京宣言」→ 政府支援を得てDRAM開発に本格参入

### 3.3 民主化以降（1987年〜）

- 1987年6月民主化抗争を経て、盧泰愚政権下で直接選挙制が導入
- 民主化後も財閥への「国策支援」構造は残存。しかし透明性・競争政策が徐々に強化
- 1997年アジア通貨危機でIMF管理下に。多くの財閥が崩壊したが、サムスンは黒字を維持し唯一生き残った大財閥の一つ

## 4. 半導体本格参入：「東京宣言」（1983年）

### 4.1 東京宣言

1983年2月、李秉喆はサムスンのDRAM事業参入を宣言。業界では後に「**東京宣言（Tokyo Declaration）**」と呼ばれる。

当時の状況：
- NEC・日立・富士通が世界DRAM市場を支配
- IntelはDRAMから撤退（日本勢に敗北）を宣言した翌年
- 業界の誰もが「韓国がDRAMで勝てるわけがない」と見ていた

### 4.2 64KB DRAMの開発（1983年12月）

宣言からわずか**6ヶ月**で、サムスンは64KB DRAMの開発に成功。

- 開発チームをロスアンゼルスの技術者アパートに集めて缶詰に
- 日本・米国から帰国した技術者（KBS——Korean Brain from Semiconductor）を大量採用
- 技術的ギャップは「10年以上」と言われていたが、**4年以内**に詰めることに成功

### 4.3 技術追い上げの構造

サムスンの技術追い上げ戦略：

| 手法 | 内容 |
|---|---|
| 海外人材採用 | 米国・日本の半導体企業の経験者を高年俸でスカウト |
| 逆エンジニアリング | 競合製品を徹底分析し、独自プロセス開発 |
| 超大型投資 | 景気後退期にも「逆張り投資」を継続。不況期に工場を増強 |
| 政府との協調 | 輸出金融・低利融資・試験研究費控除 |

## 5. 日米半導体協定（1986年）の影響

### 5.1 協定の内容と日本への打撃

1986年9月の日米半導体協定は、日本の半導体産業に直接的な打撃を与えた：
- 日本製DRAMへの**100%懲罰関税**
- 価格フロア（ダンピング禁止）による競争力低下
- 日本のDRAMシェア：1987年の**75%→2001年には20%**へ激減

### 5.2 韓国（サムスン）への棚ぼた効果

**協定の最大受益者は台湾と韓国だった。**

- 協定は「外国企業」のダンピング規制を想定しており、**韓国企業は規制対象外**
- 日本勢がフロア価格に縛られる中、サムスンは価格競争力を維持
- 1987年時点でサムスンは256KB DRAMの量産体制を確立済み

| 年 | サムスンのDRAM市場シェア | 動向 |
|---|---|---|
| 1986 | 数% | 市場参入直後 |
| 1990 | 12.9% | 東芝（14.7%）に迫る |
| 1992 | 13.5% | **東芝を抜き世界1位**に |
| 2000年代 | 30%超 | SK Hynixとあわせ韓国2社で70%超 |

## 6. 1987年：李秉喆の死去と第二創業

### 6.1 創業者の死去

李秉喆は1987年に死去。享年77歳。同年は台湾でTSMCが設立された年でもあり、半導体産業の歴史的転換点と重なる。

サムスン電子工業とサムスン半導体通信が合併し、**サムスン電子（Samsung Electronics）**として統合。

### 6.2 李健煕（イ・ゴンヒ）の時代へ

三男の李健煕（Lee Kun-hee）が会長に就任。当初は父の方針を踏襲したが、6年後の1993年に劇的な転換を宣言する。

## 7. 1990年代：DRAM世界1位への道

### 7.1 「逆張り投資」戦略

サムスンが日本・米国勢に差をつけた最大の要因が**「景気後退期の逆張り投資」**だった。

- 半導体は価格サイクルが激しい。好況→過剰投資→価格暴落→撤退という波がある
- 日米企業は価格暴落時に投資を絞る（合理的行動）
- サムスンは暴落時こそ増産投資し、回復期に**圧倒的なキャパシティを持つ先発者**として市場を制圧
- この戦略は「三星式サイクル投資」として業界のケーススタディになった

### 7.2 DRAM技術の追い上げ

| 年 | サムスンの達成 |
|---|---|
| 1983 | 64KB DRAM開発 |
| 1984 | 256KB DRAM量産 |
| 1986 | 1MB DRAM開発（東芝比1年半の遅れを2年で追いつく） |
| 1987 | 1MB DRAM量産開始 |
| 1992 | **64MB DRAM、世界初開発** → 技術ギャップを逆転 |
| 1994 | 256MB DRAM世界初 |
| 1996 | 1GB DRAM世界初。NAND型フラッシュ出荷開始 |

1992年の64MB DRAMで、サムスンは追う側から**追われる側**に転換した。

### 7.3 アジア通貨危機（1997年）の試練

1997年のアジア通貨危機で韓国はIMF管理下に入り、30大財閥のうち16社が崩壊した。サムスンは：
- 非中核事業（自動車など）を売却・縮小
- 半導体・電子に集中投資
- 危機を乗り越えた唯一の総合電子財閥として地位を固める

## 8. 李健煕の「フランクフルト宣言」（1993年）

### 8.1 宣言の内容

1993年6月7〜9日、李健煕はドイツ・フランクフルトのケンピンスキーホテルに約200名の役員・海外幹部を集め、**「新経営宣言（フランクフルト宣言）」**を発した。

「**妻と子以外はすべて変えろ（마누라와 자식 빼고 다 바꿔라）**」

### 8.2 宣言の背景

当時のサムスンの課題：
- 量産・コスト競争力はあるが、ブランド力・品質で日本勢に大きく劣る
- 米国市場での評価は「安かろう悪かろう」
- 世界の電器店でサムスン製品が棚の底に埋もれていた（視察でショックを受けた李健煕が実見）

### 8.3 宣言の結果

- 量（量産・コスト）から質（品質・ブランド・技術）への戦略転換
- 1994年：不良品15万台（約500億ウォン相当）を工場前の広場でハンマーで破壊・焼却（公開廃棄）
- 1990年代後半からブランド価値が急上昇し、2000年代にソニーを抜いて世界的な高級ブランドへ

## 9. NANDフラッシュとストレージ覇権

### 9.1 NAND型フラッシュとは

NAND型フラッシュメモリは東芝の舛岡富士雄が発明（1987年IEDM発表、1989年商品化）。DRAMと異なり電源を切っても記憶が保持される不揮発性メモリ。

### 9.2 サムスンの参入と独走

- 1996年：サムスン、NAND型フラッシュ出荷開始
- 2000年代：デジタルカメラ・携帯電話・MP3プレーヤーの普及で需要爆増
- 2002年：サムスン、NANDフラッシュ世界シェア1位を獲得
- スマートフォン時代（2010年代〜）：ストレージ需要がさらに急拡大

現在のNAND主要プレイヤー：
- サムスン（世界1位、約30%）
- SK Hynix（韓国、SK Hynix傘下のSolid State Storageを含む）
- キオクシア（旧東芝メモリ、WD傘下）
- Micron（米国）

## 10. 韓国という立地の優位性

### 10.1 地理・気候

- **温帯モンスーン気候**：四季があり、安定した気候（台湾より低温）
- **地震リスク低**：環太平洋火山帯の内側に位置し、台湾ほど地震活動は活発でない
- **台風リスク**：夏季に台風が来るが、台湾ほど頻繁ではない
- **首都圏集中**：ソウル〜水原〜華城〜平澤の軸上に半導体クラスターが集中

### 10.2 水資源

韓国の半導体産業も水消費は極めて大きい：

| 指標 | 数値 |
|---|---|
| 容仁（ヨンイン）クラスター計画水需要 | **65万トン/日** |
| 現在の対応 | 下水処理水の工業用水転換で12万トン/日確保予定 |
| 水資源協定 | 環境部・K-Water・京畿道・5市との覚書（2024年12月） |

2024年：京畿道地域の半導体サイト向け「再生水プロジェクト第1期」として、水原・龍仁・華城・烏山の下水処理場の処理水（約12万トン/日）を工業用水として利用する計画を発表。

### 10.3 電力インフラ

- 韓国電力（KEPCO）が安定供給
- 原子力発電比率が高く（約30%）、再生可能エネルギーへの移行が台湾より進んでいる
- 平澤（ピョンテク）工場は政府が送電インフラを優先整備

### 10.4 物流インフラ

**仁川国際空港（Incheon International Airport）：**
- 世界最高水準の空港（2020〜2024年連続で国際旅行者数・貨物量でトップクラス）
- 半導体・電子部品が輸出貨物の主力
- 華城・平澤工場から車で約30〜60分の圏内

**平澤港（Pyeongtaek-Dangjin Port）：**
- 平澤サムスン工場の玄関口
- 製造装置・原材料の輸入に最適化
- 2020年代に貨物取扱量が急増

**高速道路：**
- 首都圏第2外郭循環高速道路：ソウル〜水原〜華城〜平澤を連結
- 工場クラスター間をシームレスに接続

### 10.5 原材料の輸入依存構造

| 原材料 | 主要供給国 |
|---|---|
| シリコンウェーハ | 日本（信越化学、SUMCO）、台湾（GlobalWafers） |
| フォトレジスト | 日本（JSR、TOK、信越化学）——*2019年日本の輸出規制で問題化* |
| フッ化水素（エッチングガス） | 日本（ステラケミファ、森田化学）——*同上* |
| EUV露光装置 | オランダ（ASML独占） |
| 蒸着装置 | 日本・米国・欧州 |

**2019年日韓輸出管理問題：**
日本が半導体製造に不可欠な3品目（フッ化ポリイミド・フォトレジスト・フッ化水素）の対韓輸出を「包括許可」から「個別許可」に切り替え。サムスン・SK Hynixは数ヶ月分の在庫確保と国産化・調達先多様化を加速させた。これはサプライチェーンの「地政学的脆弱性」を露わにした出来事だった。

## 11. 2000年代：垂直統合の完成とスマートフォン台頭

### 11.1 垂直統合モデルの強み

サムスンはTSMCと異なり、**IDM（垂直統合型デバイスメーカー）モデル**を貫いた：

| 事業 | 内容 |
|---|---|
| DS部門（Device Solutions） | 半導体（DRAM・NAND・ファウンドリ）、ディスプレイ |
| MX部門（Mobile eXperience） | スマートフォン（Galaxy）、タブレット |
| VD/家電部門 | テレビ、白物家電 |
| ハーマン（2017年買収） | 車載インフォテインメント |

この垂直統合の恩恵：
- 自社端末（Galaxy）に最先端チップを**最も早く・最も安く**搭載できる
- チップ→ディスプレイ→端末まで一貫したコスト削減
- 一方で「顧客の競合になる」という問題もはらむ

### 11.2 Galaxyスマートフォン（2010年〜）

2010年、Androidプラットフォームの成熟を受け「Galaxy S」シリーズを投入。

- iPhoneへの対抗として**大画面・AMOLED・多機能**を武器に世界市場を席巻
- スマートフォン普及はNAND需要を爆増させ、サムスンの半導体事業を支える構造に
- 皮肉なことにGalaxy向けの最大部品サプライヤーの一つが**Apple向け半導体を製造しているサムスン自身**

## 12. AppleとのパートナーシップとTSMCへの敗北

### 12.1 「顧客であり競合」という矛盾

| 時期 | AppleとSamsungの関係 |
|---|---|
| 2007〜2011年 | iPhone・iPadのA4〜A5チップをサムスンが製造。Appleはサムスンの最大顧客の一つ |
| 2011年 | Samsung Galaxy TabがiPadの「模倣品」としてAppleが提訴。世界10カ国以上での大規模特許訴訟 |
| 2012〜2014年 | Apple、Qualcommと連携してTSMCへの移行を画策 |
| 2014年 | iPhone 6向けA8チップをTSMCが受注。Appleがサムスンから離脱開始 |
| 2015年 | iPhone 6S向けA9をサムスン（14nm）とTSMC（16nm）で分担製造 |
| 2016年〜 | **Apple、TSMC単独へ**。サムスンは完全に撤退 |

### 12.2 Appleが去った理由

- **技術的優位の逆転**：TSMCの16nm FinFETがサムスンの14nmよりも電力効率で優位と評価
- **競合問題**：顧客の設計情報が競合製品（Galaxy）開発に流用されるリスク
- **特許訴訟**：法廷闘争が続く中でサムスンへの依存を続けることへの懸念

AppleのTSMCへの全面移行は、ファウンドリ市場における「**純粋ファウンドリの信頼モデル**」の優位を決定的に示した。

## 13. ファウンドリ事業：TSMCとの差

### 13.1 サムスンファウンドリの位置づけ

サムスンはIDMとしての製造部門がファウンドリ業務も受注する形で外販を行ってきたが、2017年に**「Samsung Foundry」**として正式にファウンドリ事業を分社化。

| 指標 | Samsung Foundry | TSMC |
|---|---|---|
| 市場シェア（2024年） | 約**11%** | 約**64.9%** |
| ビジネスモデル | IDM兼業（自社製品と兼業） | 純粋ファウンドリ |
| 顧客の懸念 | 競合との情報共有リスク | ナシ（完全受託） |
| 先端ノード歩留まり | 3nm台で苦戦 | 3nm・2nmで高歩留まり |

### 13.2 サムスンファウンドリの顧客

QualcommやNvidiaはTSMCを優先しており、サムスンへの発注は限定的：

- **主要顧客**：Samsung自身（Exynos）、Google（Tensor）、Qualcomm（一部）
- **2024〜2025年**：Apple・Tesla・Nintendoからの受注も一部獲得
- **課題**：2nm（SF2）での歩留まり向上が最大の経営課題

## 15. 補助金と公的支援

### 15.1 設立〜1990年代：財閥支援の時代

| 手段 | 内容 |
|---|---|
| 政策金融 | 市場金利以下での政府系銀行融資（韓国産業銀行等） |
| 輸出振興 | 輸出実績に応じた税制優遇・補助金 |
| 研究開発補助 | DRAM開発費の政府負担（1983年東京宣言後の国家プロジェクト化） |
| 輸入保護 | 半導体完成品への関税でサムスン製品を保護 |

### 15.2 K-CHIPS法（2023年）

米国のCHIPS法・EU Chips法に対抗し、韓国も2023年に**「K-CHIPS法（国家先端전략산업법）」**を制定：

| 内容 | 詳細 |
|---|---|
| 設備投資税額控除 | 大企業：最大**25%**の投資税額控除 |
| 許認可迅速化 | Fab建設の許認可期間を3.5年→**2年**に短縮 |
| 国家産業団地指定 | ワンストップ支援窓口の設置 |

### 15.3 2024年：過去最大の半導体投資パッケージ

2024年5月、韓国政府は過去最大規模の半導体支援パッケージを発表：

- **23兆ウォン（約190億ドル）**の官民連携支援
- サムスン・SK Hynixが主要受益者
- 関税リスク（米国トランプ政権）への対応も目的の一つ

### 15.4 米国CHIPS法補助金

| 対象 | 金額 |
|---|---|
| Samsung Austin（CHIPS法） | 約**64億ドル** |
| Samsung Taylor新Fab | 計画継続中 |

## 16. 資源問題と環境対応

### 16.1 水問題

韓国でも半導体工場の水問題は深刻化している：

- 龍仁半導体クラスター（計画中）の水需要：**65万トン/日**
- 現行の上水道からの供給だけでは賄えないため、下水処理水の再利用が急務
- 2024年：京畿道5市と覚書。下水処理水（12万トン/日）を工業用水転換するプロジェクト推進

### 16.2 電力問題

- 半導体工場はデータセンターと並んで最大の電力消費産業
- 韓国電力（KEPCO）の送電インフラ整備が工場拡張のボトルネックに
- 政府が平澤・龍仁の電力インフラ整備を優先

### 16.3 サムスンの環境認証

- 韓国の全製造拠点がAWS（Alliance for Water Stewardship）プラチナ認証を取得（最高レベル）
- Carbon Trust「トリプルスタンダード（炭素・水・廃棄物）」認証を業界初取得
- 2024年：韓国工場の水使用量の100%を補充

## 17. 李在鎔（イ・ジェヨン）の時代：スキャンダルと後継体制

### 17.1 李健煕の半身不随（2014年）

2014年5月、李健煕が心筋梗塞で倒れ意識不明の重体に。2020年10月に死去。

これを機に、後継者の李在鎔（孫）が実質的な経営権を握り始める。

### 17.2 朴槿恵大統領弾劾事件との連鎖（2017年）

2016〜2017年の「崔順実ゲート」（大統領の親友による国政介入スキャンダル）に、サムスンが連座：

- サムスン系の国民年金公団が李在鎔の相続（サムスンC&T・第一毛織合併）を支持
- その見返りとして崔順実の関連財団に**430億ウォン（約38億円）**の支援
- 2017年8月：李在鎔に**懲役5年**の実刑判決（後に2.5年に減軽）
- 2024年2月：ソウル高裁が**無罪判決**

この一件は「財閥と政治の癒着」という韓国社会の構造的問題を改めて浮き彫りにした。

### 17.3 経営への影響

- 李在鎔が逮捕・拘留中、サムスンは「一時的リーダーシップの空白」を経験
- 中長期的な大型意思決定（工場建設・M&A）が遅延したと言われる
- 2022年8月：特赦で釈放、経営への復帰を本格化

## 18. 2020年代：HBM・AI・地政学

### 18.1 HBM（高帯域幅メモリ）の競争

AIブームによりGPU向けHBM（High Bandwidth Memory）の需要が急増：

| 企業 | HBM市場での位置 |
|---|---|
| SK Hynix | HBM3e（8スタック）でNvidiaへの供給を先行。市場シェア約50% |
| **サムスン** | HBM3Eの歩留まり・品質問題でNvidiaの承認遅れ。2023〜2024年に課題が表面化 |
| Micron | HBM3eで台頭 |

サムスンはDRAMの王者でありながら、AIチップ向けHBMでSK Hynixに遅れを取るという状況が2023〜2024年の業績悪化の一因となった。

### 18.2 ファウンドリの苦戦

- 3nmノードの歩留まり問題が深刻化。Qualcomm・TensorからTSMCへ流出
- 2024年：Samsung Foundryが大規模なコスト削減・人員削減を発表
- 2025年以降：SF2（2nm）での逆転を目指す

### 18.3 中国リスクと地政学

- 西安工場（NAND生産の40%）が米中摩擦のリスクにさらされている
- 米国の対中輸出規制強化でサムスンは「中国工場の維持と拡張」の両立に苦心
- 2023年：米国から「無期限の設備輸出免除」を獲得したが不確実性は残る

### 18.4 現在の規模感（2024年）

| 指標 | 数値 |
|---|---|
| 売上高（2025年度） | 約**333.6兆ウォン（約2500億ドル）** |
| 半導体部門売上 | 約100兆ウォン超 |
| 半導体世界シェア | **10.6%**（IDMとして総合半導体では最大規模） |
| ファウンドリシェア | 約**11%**（TSMC 64.9%と大差） |
| DRAM世界シェア | 約**40%**（SK Hynixと合わせ韓国勢で約73%） |
| NAND世界シェア | 約**30%** |
| 従業員数 | 約27万人（グループ全体） |
| 時価総額 | 約3000億ドル（TSMCの約3分の1） |

## 19. TSMCとの比較

| 項目 | サムスン | TSMC |
|---|---|---|
| 創業 | 1938年（半導体参入は1974年） | 1987年 |
| ビジネスモデル | IDM（設計・製造・販売の垂直統合） | 純粋ファウンドリ（製造に特化） |
| 顧客との競合 | あり（自社端末・メモリ） | なし（これが最大の差別化） |
| 最先端ノード | 3nm稼働（2nm開発中、歩留まり課題） | 2nm量産中（歩留まり優位） |
| ファウンドリシェア | 約11% | 約65% |
| 政府との関係 | 財閥として深い癒着の歴史 | 国家戦略企業として支援を受けるが癒着は少ない |
| 海外展開 | 米国テキサス・中国西安 | 米国アリゾナ・日本熊本・ドイツドレスデン |
| Apple依存 | 2015年に失った（競合問題） | Apple売上の25%（最大顧客） |
| 強み | メモリ（DRAM・NAND）・垂直統合 | 先端ファウンドリの信頼・エコシステム |
| 弱み | 顧客信頼性・ファウンドリ歩留まり | メモリ非保有・台湾地政学リスク |
