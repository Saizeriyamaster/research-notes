# ベインキャピタル (Bain Capital) — CoAnal 企業解剖

**分析日:** 2026-06-17

---

## TL;DR

> コンサルティングファーム出身のDNAを武器に、**「オペレーション改善でリターンを生む」PE業界の異端児**。AUM $225Bの総合オルタナ運用会社として、PE・クレジット・不動産・ベンチャーを横断する。日本では半導体（キオクシア）・小売（ヨーカ堂）・デジタルインフラ（インフォリッチ）に集中投資し、「再建型PE」として存在感を示している。

## ③ ビジネスモデル解剖

```
収益構造マップ:
[LP（年金基金・SWF・大学基金）]
    → [ファンド組成・投資実行]
    → [管理報酬（約2%/年）+ キャリード・インタレスト（利益の約20%）]
    → [オペレーション改善によるバリューアップ → EXIT（IPO・売却）]
```

**差別化の核心: コンサルDNA**
- 過去10年の価値創造の**約80%がオペレーション改善由来**（財務レバレッジは20%）
- 買収後に経営コンサルタントのように介入し、売上拡大・コスト削減・新市場進出を推進
- ベイン＆カンパニーとの非公式な知見ネットワークが他社との差別化要因

## ⑧ 経済的護城河（Moat）分析

| Moat類型 | 評価 | 根拠 |
|---------|------|------|
| コスト優位 | △ | 大規模ファンドに比べると規模の経済で劣る |
| 無形資産（ブランド・実績） | ◎ | 「コンサル×PE」の独自ブランド。LPからの資金調達力が高い |
| スイッチングコスト | ○ | LP（投資家）との長期関係性。乗り換えコスト高い |
| ネットワーク効果 | △ | 業界ネットワーク・元コンサル人脈は強いが複製可能 |
| オペレーション知識 | ◎ | 業種横断のオペ改善ノウハウは他社が模倣困難 |

> **総合Moat評価: Narrow（狭い護城河）** — ブランドとオペレーション知識は本物だが、AUM規模と分散化でKKR・ブラックストーンに後れを取る。ただし「規模より質」を追うスタンスは一貫しており、LP満足度では高評価を維持。

## ⑨ 最新動向（2025〜2026）

| 時期 | 動向 |
|------|------|
| 2025年10月 | 旗艦PEファンド XIV を**$140億**でクローズ（前ファンドより約30%増） |
| 2025年 | クレジット部門が2025年通年で**$80億**の融資投資を実行 |
| 2026年1月 | 不動産ファンドIII を**$34億**でクローズ（新規$50億調達の一環） |
| 2026年4月 | インフォリッチのMBO完了・上場廃止（+123%プレミアム） |
| 2026年5月 | アジア専用ファンドVI を**$105億**でクローズ（アジア最大級の調達の一つ） |
| 2026年進行中 | イトーヨーカ堂（ヨーク・ホールディングス）の優先交渉継続中 |
| 2026年進行中 | キオクシア持分の段階的売却（IPO後に$35億・$20億相当を市場売却） |

**注目ポイント:** ベインはアジア・日本を「次の大型バリューアップ市場」として最重視している。アジアファンドVI（$105億）は同社史上最大のアジア向けファンドであり、日本の企業再編（カーブアウト・MBO）に積極的に参加する姿勢が鮮明。
