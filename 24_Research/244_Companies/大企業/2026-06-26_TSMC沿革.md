## 1. 設立前夜：背景と文脈

### 1.1 日米半導体協定（1986年）の衝撃

1986年9月2日、米国と日本は「日米半導体協定（U.S.–Japan Semiconductor Agreement）」に署名した。背景は1980年代前半の日本の半導体産業の爆発的成長にある。

- 1985年時点で日本はDRAM市場の世界シェア**50%超**を保有
- NEC・東芝・日立・富士通・三菱がグローバル市場を席巻
- Intelはメモリビジネスを日本勢に奪われ、マイクロプロセッサへの集中を余儀なくされた

協定の内容：
- 日本製半導体の輸出に**最低価格（フロアプライス）**を設定
- 米国が100%の懲罰関税を日本製DRAMに賦課
- 日本の国内市場における外国企業のシェアを**20%以上**に引き上げることを義務化

この協定は**「自由競争のルールを政治で歪めた」**と解釈する向きもあったが、結果として日本のIDM（垂直統合型デバイスメーカー）ビジネスモデルに亀裂を入れた。日本勢は技術力ではなく政策によって守られていたが、それが逆に変革を遅らせる要因となった。

**台湾にとっての追い風：**
- 日本勢が規制に縛られている間に、台湾は全く異なるビジネスモデル（純粋ファウンドリ）を構築
- 米国は日本に対抗するためのサプライチェーン多元化を必要としており、台湾への技術移転を黙認・後押し
- TSMCはこの協定翌年の1987年に設立されており、タイミングは偶然ではない

### 1.2 台湾の半導体戦略の萌芽（1960年代〜1980年代）

| 年 | 出来事 |
|---|---|
| 1960年代 | 台湾、外資誘致型の輸出加工区を設置。フェアチャイルドやTIが生産拠点を置く |
| 1973年 | ITRI（工業技術研究院）設立。国主導の技術開発機関 |
| 1976年 | 政府がRCA（米国）を説得し、半導体技術を台湾に移転させる。ITRIのエンジニアチームがRCAで研修 |
| 1980年 | 新竹科学工業園区（新竹サイエンスパーク）設立。大学・研究機関との一体的クラスター形成 |
| 1985年 | モリス・チャン、台湾へ。ITRIの総裁に就任 |
| 1986年 | 日米半導体協定締結 |
| 1987年 | TSMC設立 |

## 2. 創業者モリス・チャンの軌跡

### 2.1 テキサス・インスツルメンツ時代

モリス・チャン（張忠謀、Morris Chang）は1931年中国・寧波生まれ。1958年にTIに入社し、半導体製造の最前線で30年近くキャリアを積む。

- TI時代、**日本工場の歩留まりがテキサス工場の2倍**であることを目撃
- 「製造の未来はアジアにある」という確信を深める
- TIのグループリーダーとして利益部門を統括するも、CEO昇格は叶わなかった

### 2.2 General Instrument（1984〜1985年）

TIを離れたチャンはGeneral Instrumentの社長兼COOに就任するが、文化的ミスマッチから1年で離職。

### 2.3 台湾へ——ITRIの総裁（1985年）

台湾政府の経済長老・孫運璿（当時行政院長）の招聘を受け、1985年にITRI総裁として台湾入り。

- K.T. Li（李国鼎）が「白紙小切手」を提示し、半導体産業構築を一任
- チャンは台湾の潜在力を見抜き、全く新しいビジネスモデルの可能性を確信

## 3. 設立（1987年）：政府持株・政治状況・資本構成

### 3.1 資本構成

| 株主 | 出資比率 | 金額（概算） |
|---|---|---|
| 台湾政府（行政院国家発展基金） | **48.3%** | 約1億ドル |
| フィリップス（オランダ） | **27.5%** | 5800万ドル |
| 民間投資家（台湾地場企業） | **24.2%** | 残余 |

**総資本金：約2億ドル**（当時の台湾GDP比では極めて大規模な国家プロジェクト）

フィリップスは単なる出資者ではなく、**生産技術ライセンスとIPの移転**を条件として参画。これがTSMCの初期技術基盤を形成した。

### 3.2 台湾の政治状況——戒厳令の時代

TSMC設立の1987年は、台湾の政治史上の大きな転換点と重なる。

| 事実 | 内容 |
|---|---|
| **政権** | 蒋経国（Chiang Ching-kuo）国民党（KMT）政権 |
| **戒厳令** | 1949年から実施（38年間）→ **1987年7月15日に解除** |
| **民主化** | 同年1986年、民主進歩党（民進党）が非合法ながら結党。政府は黙認 |
| **政治体制** | 実質的権威主義体制。多党選挙は未実施。国民大会・立法院は1948年選出の議員が居座り続ける |
| **対外関係** | 1979年に米国が中国（PRC）と国交を正常化し、台湾と断交。国際的孤立の深まる中での産業戦略 |

つまり、**TSMC設立はまだ独裁体制の末期に行われた国家主導プロジェクト**だった。民主化（戒厳令解除）と同年のことであり、蒋経国政権が半導体産業立国を国策として推進した。

蒋経国が1988年に死去した後も、後継の李登輝政権（KMT改革派）はTSMCを引き続き支援。1990年代に民主化が進むにつれて、半導体産業は国家の象徴的産業として超党派で支持された。

## 4. ファウンドリモデルという革命

### 4.1 従来のIDMモデルとの比較

| 項目 | IDM（従来型） | ファウンドリ（TSMC） |
|---|---|---|
| 事業範囲 | 設計・製造・販売を垂直統合 | 製造のみに特化 |
| 顧客との関係 | 競合になりうる | 顧客の競合にならない（純粋サービス） |
| 代表企業 | Intel, Toshiba, NEC, Hitachi | TSMC, UMC |
| 設備投資 | 分散（設計・マーケも要) | 製造に集中投資 |
| リスク | 自社製品の市場リスクを負う | 顧客からの受注リスクのみ |

### 4.2 「競合しない」という信頼設計

チャンが徹底したのは「**純粋ファウンドリは決して自社製品を売らない**」という原則だった。

- IDMは自社製品の余剰生産分を外注（スポット受注）していたが、これは顧客から見ると「秘密を競合に教える」行為
- TSMCは顧客と守秘義務を徹底し、「ファウンドリは顧客の軍需産業工場」という概念を定着させた
- この信頼設計がNvidia、Qualcomm、AMDといった後のファブレス企業群を生み出す土台となった

## 5. 1990年代：成長期と市場開拓

### 5.1 初期顧客獲得の戦略

TSMCの創業期は決して順風満帆ではなかった。

- **1987〜1990年**：低マージンの下請け仕事（IntelやMotorolaの**余剰生産分**）が主
- Intelは1987年に最初の米国顧客になるも、あくまで補完的発注
- 当時の「顧客の秘密を守る製造専業」というコンセプトは業界にまだ受け入れられていなかった

顧客獲得の転換点：
- **Altera**（1988年）：プログラマブルロジックデバイスを作るファブレス新興企業
- **Xilinx**（1990年代初頭）：FPGA分野のファブレス企業
- これらファブレス・スタートアップはTSMCなくして存在できなかった

### 5.2 株式公開と資金調達

| 年 | イベント |
|---|---|
| 1994 | 台湾証券取引所（TWSE）上場 |
| 1997 | NYSE（ニューヨーク証券取引所）にADR（米国預託証書）上場。**台湾企業として初** |

### 5.3 プロセス技術の進化

| 年 | プロセスノード |
|---|---|
| 1987 | 1.5μm（設立時） |
| 1990 | 1.0μm |
| 1994 | 0.5μm |
| 1996 | 0.35μm |
| 1998 | 0.25μm |
| 1999 | 0.18μm |

### 5.4 1999年台湾大地震の試練

1999年9月21日の集集地震（M7.6）はTSMC工場にも被害をもたらしたが、**3日以内に生産再開**という迅速な対応でむしろ「危機管理能力」を世界に示すことになった。

## 6. 台湾という立地の優位性

### 6.1 地理・気候

- **亜熱帯性気候**：一定の高温多湿環境がチップ製造プロセスに（冷却コスト面で）適している
- **地震リスク**：太平洋プレート上にありリスクあり。しかし1999年の経験を経て耐震設計が進化
- **台風リスク**：夏季の台風は脅威だが、同時に**降水量をもたらすメリット**もある

### 6.2 電力インフラ

- 台湾電力（台電）が安定した電力を供給
- 現在TSMC単社で台湾の**電力消費量の約8%**を占める
- 主要電源は化石燃料（石炭・天然ガス）が約84%。再生可能エネルギーへの転換が課題
- TSMCは2025年までに**100% 再生可能エネルギー**使用を目標

### 6.3 水資源——最大の制約

チップ製造には膨大な超純水（UPW）が必要：

| 規模 | 数値 |
|---|---|
| TSMCの一日当たり水使用量 | **約15万トン** |
| 新竹サイエンスパークの水道消費 | 宝山・第二宝山ダムの日供給量の10.3% |

**2021年の大干ばつ危機：**
- 50年に一度の渇水。貯水率が過去最低を記録
- 政府は農地への用水供給（約18万3000エーカー）を停止し、半導体工場への優先配水を決定
- 農業従事者から「工場のために農家が犠牲になる」と強い批判
- TSMCはタンクローリー調達・自前の水リサイクルプラントを建設

### 6.4 原材料の輸入体制

TSMCが使用する主要原材料はほぼ全量が輸入：

| 原材料 | 主要供給国 |
|---|---|
| **シリコンウェーハ** | 台湾（GlobalWafers）、日本（信越化学、SUMCO）、ドイツ（Siltronic） |
| **化学品・特殊ガス** | 日本、米国、ドイツ |
| **フォトマスク** | 日本（DNP、凸版印刷）、米国 |
| **フォトレジスト** | 日本（TOK、JSR） |
| **EUV露光装置** | オランダ（ASML独占） |

日本と台湾の**材料サプライチェーン依存関係**は、政治的な緊張があっても切れない深い経済的結合を生んでいる。

### 6.5 物流インフラ：高速道路・港湾・空港

**桃園国際空港（Taiwan Taoyuan International Airport）：**
- 新竹サイエンスパークから約40km
- 2024年の貨物取扱量：**約235万トン**（うち電子・半導体・精密機械が**62%**）
- 世界15位以内の空港貨物量
- FedExが2026年にトランシップメントセンターを大幅拡張（1.9万㎡、輸入効率2.5倍）
- チップは単位重量当たりの価値が極めて高いため**航空輸送が主流**

**高速道路：**
- 国道1号（台湾高速公路）：台北〜高雄を縦断
- 新竹ICを経由した南北アクセスにより、新竹・台中・台南・高雄の工場クラスターを連結
- 南部科学工業区（台南）へのアクセスも整備

**港湾：**
- 基隆港・高雄港：重量物（製造装置・原材料）の輸入に使用
- EUV露光装置（1台数百億円超）は防振・専用コンテナで海上輸送後、陸送

## 7. 競合との戦い：日本・韓国・Intel

### 7.1 日本企業との競合

1980年代後半〜1990年代、日本の半導体メーカーは以下の通り圧倒的な存在感を持っていた：

| 企業 | 強み |
|---|---|
| NEC | DRAM世界シェア1位（1985年） |
| 東芝 | NAND型フラッシュメモリの発明（1987年） |
| 日立 | DRAM・ロジック半導体 |
| 富士通 | MPU・SRAM |
| 三菱 | メモリ |

**日本勢の限界：**
- IDMモデルの固執：製造装置・プロセス・設計を全て自前で抱える構造
- 組織の縦割り、顧客企業への技術開示を嫌う文化
- 1986年協定後の価格規制による収益圧迫
- 90年代後半の「失われた10年」とバブル崩壊による設備投資の停滞

TSMCのファウンドリモデルは日本の競合には脅威でも機会でもあった。しかし日本企業はTSMCに発注する形でファブレス化・外注化する決断が遅く、韓国・台湾に製造の主導権を奪われていった。

### 7.2 韓国（サムスン）との競合

| 年代 | 状況 |
|---|---|
| 1990年代 | サムスンはDRAMで台頭。製造ノウハウはIDMとして内製 |
| 2000年代 | サムスンが初めてファウンドリサービスを開始。しかし自社製品と兼業のため顧客の信頼薄い |
| 2010年代 | AppleがサムスンからTSMCへ切り替え（2014年A8チップ）。サムスンが「顧客情報を自社製品開発に利用する」懸念 |
| 2020年代 | TSMCのファウンドリシェア**64.9%**（2024年Q3）対サムスン約11% |

TSMCが「**顧客と競合しない**」という純粋ファウンドリ原則を貫いたことが、サムスンとの差別化の核心だった。

### 7.3 Intelとの関係

Intelは1987年にTSMCの最初の米国顧客になったが、あくまで余剰生産の発注にとどまった。

- Intelは長く「IDM自社製造こそ競争優位」として独自プロセスを磨き続けた
- しかし2010年代に10nm以降の開発で遅れ、2020年代に入り自社製造の競争力が低下
- 2020年代：IntelはTSMCへの製造外注を増やし始め、事実上の「ファウンドリモデルへの屈服」
- 2021年：Intel Foundry Services（IFS）設立。TSMC追撃を図るが市場シェアは依然低迷

### 8.2 Open Innovation Platform（OIP）の立ち上げ（2008年）

TSMCは2008年に**EDA（電子設計自動化）ツールベンダーやIP会社**と連携した「オープンイノベーションプラットフォーム」を構築。

- 設計ツールとプロセスの最適化を顧客企業と共同で行う
- Arm、Cadence、Synopsysなどとのエコシステムを形成
- これにより**「TSMC向けに最適化された設計環境」**が整備され、ファブレス企業の参入障壁が劇的に低下

### 8.3 2001年：世界最大のファウンドリに

2001年、TSMCは世界最大の専業ファウンドリとして市場シェア50%超を確立。

## 9. 2010年代：Appleと先端プロセスの深化

### 9.1 AppleとTSMCの蜜月（2014年〜）

| 年 | 出来事 |
|---|---|
| 2010年 | Appleが初代iPhone向けA4チップをサムスンに発注。TSMC接触開始 |
| 2014年 | **iPhone 6（A8チップ）**でTSMCが初の量産受注。サムスンから切り替え |
| 2015年〜 | 20nm→16nm FinFETへの移行でTSMCが先行 |
| 2016年〜 | TSMCがApple向けに専用工場群を構築（初期投資90億ドル、6000人専属） |
| 2024年 | Appleは**TSMCの年間売上の約25%**（約180億ドル）を占める最大顧客 |

この構造的依存は相互的で：
- AppleはTSMCなしにiPhone/iPad/Macのチップを製造できない
- TSMCはAppleなしに最先端プロセスへの巨大投資を回収できない

## 10. 海外工場の歴史

### 10.1 WaferTech（米国ワシントン州）——1996年

| 項目 | 内容 |
|---|---|
| 設立 | 1996年、米国ワシントン州Camas |
| 形態 | TSMC主導の合弁。Altera、Analog Devices、ISSIなどが出資 |
| 投資額 | **約12億ドル**（当時ワシントン州最大のスタートアップ投資） |
| 意義 | **米国初の純粋ファウンドリ** |
| 課題 | コスト超過・台湾本社との調整難航。同一製品でも台湾比**利益率20〜25%低下** |
| 2010年 | TSMC完全子会社化 |
| 2023年 | 「TSMC Washington」に改名 |

WaferTechの経験は、**海外製造の難しさ（コスト・文化・マネジメント）**を早期に認識させ、以降TSMCが海外展開に慎重だった背景となった。

### 10.2 台湾国内の工場網（主要Fab）

台湾国内に集中する構造：

| 工場 | 場所 | 主要ノード |
|---|---|---|
| Fab 2〜6 | 新竹 | レガシーノード |
| Fab 12 | 新竹 | 先端ノード（7nm〜） |
| Fab 14 | 台南・南部科学工業区 | 先端ノード |
| Fab 15 | 台中 | 先端ノード |
| Fab 18 | 台南 | **5nm/3nm/2nm最先端** |

新竹・台中・台南の3都市に分散配置されており、港湾（高雄港・基隆港）・桃園空港へのアクセスも考慮されている。

## 11. 補助金と公的支援の歴史

### 11.1 設立期（1987年）

| 項目 | 金額 |
|---|---|
| 台湾政府出資 | **約1億ドル**（国家発展基金） |
| 総資本金 | 約2億ドル |
| 対GDP比 | 当時の台湾GDPは約1000億ドル規模。国家予算の数%相当 |

### 11.2 継続的な優遇措置（1990年代〜）

- 法人税減税（Science Park内企業への5年免税措置）
- R&D費用の税額控除
- 土地使用料の優遇（科学工業区内）
- 政府系研究機関（ITRI）との共同開発

### 11.3 現代の補助構造

| 国・地域 | 補助額 | 対象 |
|---|---|---|
| **台湾** | 継続的な税制優遇・R&D補助 | 国内投資全般 |
| **米国（CHIPS法）** | 66億ドル補助 + 50億ドルローン | Arizona Fab建設 |
| **日本** | 4760億円（約33億ドル） | 熊本JASM |
| **EU（EU CHIPS法）** | 約50億ユーロ | ドレスデンESMC |

米国と欧州がここまで巨額の補助金を積んでTSMCを誘致した背景：
- COVID-19パンデミックによるチップ不足（2020〜2021年）
- 中国リスクへの対応（台湾海峡危機シナリオ）
- 「経済安全保障」の文脈での半導体国産化

## 12. 資源問題と世論

### 12.1 水問題の深刻化

| 指標 | 数値 |
|---|---|
| TSMC一日水使用量 | 約15万トン |
| 2030年予測 | 2022年比2倍の需要見込み |
| 現在の水リサイクル率 | わずか**3.2%**（残り96.6%は自然水源） |
| 電力のうち化石燃料 | 約84% |

**農業との対立：**

2021年の大干ばつでは、政府が農地18万3000エーカーへの灌漑を停止し、半導体工場優先を決定。農業従事者は「食料安全保障よりチップ産業が優先されている」と批判した。

ある水管理専門家は「政府は経済成長のためにチップ工場に過度に便宜を図っている。『必要なものは何でも用意する』という方針だ」と述べた。

### 12.2 TSMC自身の環境対応

- 2021年：自前の水リサイクルプラント建設開始
- 2030年目標：水使用量を2010年比**30%削減**
- 南部科学工業区に日産1万トンの水リサイクル施設を稼働（2026年に3.6万トンへ拡大予定）
- 電力：2025年の100%再生可能エネルギー使用目標（達成は困難な状況）

### 12.3 世論の変遷

| 時期 | 世論の傾向 |
|---|---|
| 1987〜1990年代 | 雇用創出・輸出産業として肯定的評価。産業界全体が後押し |
| 2000年代 | TSMC神話の確立。「台湾のシリコンシールド」として誇りの対象 |
| 2010年代 | 電力・水不足への懸念が浮上するも、経済的メリットが優勢 |
| 2021年〜 | 農業との水資源争奪で批判増。「半導体のために農業が犠牲」という声 |
| 現在 | 地政学的存在感（台湾の安全保障への貢献）と環境負荷のトレードオフが議論の中心 |

## 13. 2020年代：地政学とシリコンシールド

### 13.1 「シリコンシールド」論

TSMCが台湾の「盾」になるという議論が国際政治で広まった。

- 中国が台湾を武力統一した場合、TSMC（世界の先端チップ製造の約9割を担う）が機能しなくなる
- iPhone、Macbook、Nvidia GPU、自動車のECUなど全世界の産業が停止
- 「TSMCを守ることは世界経済を守ること」——これが台湾の安全保障上の非公式な抑止力

ただし、この論理の脆弱性も指摘される：
- 「TSMCが欲しいがために中国が侵攻するかもしれない」という逆説
- 地理的集中リスク（台湾島に98%超の最先端製造が集中）

### 13.2 2024年時点の規模感

| 指標 | 数値 |
|---|---|
| 時価総額 | **1兆ドル超**（2024年）、世界10位以内 |
| 年間売上高 | 約**2.9兆台湾ドル（約880億ドル）**（2024年） |
| ファウンドリ市場シェア | **64.9%**（2024年Q3） |
| 先端プロセス（3nm以下）シェア | **90%超** |
| 主要顧客 | Apple（25%）、Nvidia（11%）、AMD（7%）他 |
| 顧客数 | **600社超** |
| プロセスノード | 2nm（N2）量産中（2025年〜） |

### 13.3 NvidiaとAI半導体時代

2020年代のAIブーム（特にGenerative AI）で需要が急騰：

- H100、A100 GPU（Nvidia）はすべてTSMC製
- CoWoS（Chip on Wafer on Substrate）パッケージング技術でHBMとGPUを統合
- AI向け先端チップはほぼ全量がTSMCに依存
- 2025〜2026年：TSMCのCoWoSキャパシティ逼迫が業界全体のボトルネックに
