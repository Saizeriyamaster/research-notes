# 高砂熱学工業 — CoAnal 企業解剖

**分析日:** 2026-04-12

---

## TL;DR

「精密な空気」を売る設備工事の絶対王者。半導体工場・データセンターという時代の最大公約数需要を背景に、売上より**はるかに速い速度で利益が爆増中**。14年連続業界首位という無形資産と、施工後の保守契約という高いスイッチングコストが二重の堀を形成している老舗成長企業。

## バリュエーション

| 指標 | 値 | 業界平均目安 | 備考 |
|------|---|------------|------|
| PER（株価収益率） | 約18倍（予想） | 建設業 15〜20倍 | 成長プレミアムが乗っている水準 |
| PSR（株価売上高倍率） | 約1.8倍 | 建設業 0.3〜0.8倍 | 設備工事業としては異例の高PSR |
| PBR（株価純資産倍率） | 約3.3倍 | 建設業 1.0〜1.5倍 | 資産ではなく「稼ぐ力」が評価されている |
| EV/EBITDA | 約6.6倍 | 建設業 5〜8倍 | 相対的には適正圏 |
| 配当利回り | 約2.2%（予想） | — | 増配継続方針（2024年に14円/株積み増し） |
| 時価総額 | 約7,042億円 | — | 中堅ゼネコンを逆転する水準に接近 |

**バリュエーション判定:**
「適正〜やや割高」だが成長ストーリーは織り込み途上。PBR3.3倍・PSR1.8倍は設備工事業として異例の高水準だが、利益率が今後も改善し続けるならば正当化できる。2026年3月期営業利益が500億円に到達すれば、PER18倍は実質的に割安圏に入る逆転現象が起きうる。

## ビジネスモデル

```
収益構造マップ:

[顧客セグメント]         [提供価値]              [収益モデル]
 半導体・製薬工場  ─→  精密クリーンルーム空調  ─→  受注工事（高単価）
 データセンター    ─→  冷却・電力効率最適化    ─→  受注工事
 病院・研究施設   ─→  衛生・温度制御         ─→  受注工事 + 保守契約
 オフィス・商業   ─→  快適・省エネ空調        ─→  受注工事 + 保守契約
 官公庁・インフラ  ─→  長期設備管理           ─→  長期保守契約（ストック型）
```

**4つの事業ドメイン:**
1. 建設事業（主力・フロー収益）
2. 保守管理事業（ストック収益）
3. カーボンニュートラル事業（改修需要）
4. 環境機器製造・販売（自社製品）

**主要クライアント・顧客:**

| クライアント/セグメント | 売上比率(目安) | 関係の特徴 |
|----------------------|-------------|----------|
| 半導体工場（三菱電機・TSMC関連等） | 拡大中（最重要） | クリーンルーム施工→保守で長期囲い込み |
| データセンター（国内外クラウド大手） | 急増中 | 冷却設備・電源インフラ一体受注 |
| 病院・製薬・バイオ施設 | 安定した中核 | 感染制御・恒温要求で技術難易度が高く高採算 |
| オフィスビル・商業施設 | 安定 | ゼネコン経由の下請け〜元請け両方 |
| 官公庁・公共施設 | 安定（低成長） | 長期メンテナンス契約で収益安定性に寄与 |

## 経営チーム・文化

**代表取締役社長 小島和人**氏——設備工事エンジニアリング出身の生え抜き経営者。

- **タカサゴ・アカデミー:** 入社後2年間、全員が現場OJTを経験。3年目以降はジョブローテーション＋選択型教育
- **「助太刀社員」制度:** 協力会社からの人材受け入れで施工体制を補強
- **採用強化:** 2024年以降、年間350名超の採用を方針化
- **文化:** 技術の深化・現場力重視の着実な文化。宇宙事業参入がカルチャー変化の象徴

## 強み・リスク

| 強み (Strengths) | リスク (Risks) |
|-----------------|--------------|
| 空調設備工事14年連続首位のブランド | 半導体工場偏重——景気後退時の受注急減リスク |
| クリーンルーム精密空調の技術的参入障壁 | 建設コスト上昇（資材・労務費のインフレ） |
| 保守ストック収益によるフロー/ストックの二重構造 | 職人・施工管理者の慢性的な人手不足 |
| 半導体・データセンター特需の直撃受益 | 超大型案件の工程遅延・採算悪化リスク |
| 財務健全性（自己資本比率53.9%） | 海外展開のスケールが大気社に劣後 |
| 宇宙・水電解という次世代R&D資産 | — |

**成長ドライバー:**
1. 半導体・データセンター特需の長期継続（2030年代まで）
2. カーボンニュートラル改修需要の爆発（既存建物GHG削減義務化）
3. 営業利益率の構造的改善（6%台→10%台へ）——高付加価値案件シフト×DX効率化

## 最新動向

- **2026年3月期Q3:** 経常利益414億円（前年同期比+81%）、通期予想を460→500億円に再上方修正
- **株価:** 2024年5月に上場来高値更新。時価総額7,000億円超
- **中期経営計画2026:** 最終年度経常利益目標を200億→300億円に大幅引き上げ
- **グローバル戦略:** 中国・タイ・ベトナムなどアジア事業を強化。国際グループ事業統括部を新設済み
- **人材戦略:** 350名超の年間採用を目標化
