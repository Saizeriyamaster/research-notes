# HRT 2015インターン・マフィア：次世代テック帝国の同窓生たち

> Hudson River Tradingの2015年インターン同期が、2020年代最大のスタートアップ群を生み出した

---

## TL;DR

クオンツHFT最高峰のHRTに、2015年前後に集まった数学・CS天才集団が、その後 **合計時価総額20兆円超** のスタートアップを創業。「次のPayPalマフィア」と呼ばれる所以。共通点は「競技プログラミング/数学オリンピックの金メダリスト」レベルの頭脳と、HRTで培った「数学×速度×ゼロ人情」の思考回路。

---

## 0. インターン元：Hudson River Trading（HRT）

| 項目 | 内容 |
|------|------|
| 設立 | 2002年、NY |
| 種別 | クオンツ系HFT（超高速アルゴリズム取引） |
| 規模 | 社員800人以上、米国株式市場の取引量**約10%**を占有 |
| 売上 | 2024年 約80億ドル、2025年 約120億ドルペース |
| 取引対象 | 株式・先物・オプション・金利・クレジット・暗号資産（100以上の市場） |
| 採用 | 数学者・物理学者・CS博士が中心。インターンは本番と同じインフラ・データに触れる |

**なぜ最高峰か**：HFTは「1マイクロ秒（=人の瞬きの1/30万）」の世界で戦う。HRTはその中でも平均保有時間5分と中長期派で、2024年売上80億ドルは業界トップクラス。インターン採用は競技プログラミング・数学オリンピックレベルが前提。

## 1. Hyperliquid（ハイパーリキッド）

| 項目 | 内容 |
|------|------|
| 分野 | 分散型取引所（DEX）＋ 独自Layer 1ブロックチェーン |
| 時価総額 | 約154〜174億ドル（2026年時点）|
| 創業者 | **Jeff Yan**（ハーバード大、国際物理オリンピック金メダル） |
| チーム規模 | **たった11人** |
| 調達 | **VC資金ゼロ** |
| 年間売上 | 約9億ドル |
| 1日取引量 | 約100億ドル |

**何をやっているか**：「ビットコインやイーサリアムを証拠金にして、仮想通貨の先物取引ができる分散型取引所」。銀行もブローカーも不要。コードが取引を自動執行する。

**HRTとの繋がり**：Jeff YanはHRTのインターン中にイーサリアムの技術論文を発見し、「これは銀行を置き換える」と確信。2019年にプエルトリコで暗号資産マーケットメイク会社（元手1万ドル）を立ち上げ、年率数千%で成長。その後Hyperliquidを創業。

## 背景知識：理解に必要な3つのテクノロジー

### A. HFT（高頻度取引）とクオンツ取引

```
クオンツ取引 = データ分析+統計モデルで相場のパターンを発見し自動売買
HFT = その中でも「マイクロ秒単位の超高速」を武器にする戦略
```

- 人間の瞬きは30万マイクロ秒。HFTは1マイクロ秒で売買完了
- 取引所の隣にサーバーを置く（コロケーション）だけで数十マイクロ秒有利になる
- 利益は1回の取引では微々たる「価格のズレ」。それを1日何百万回繰り返す
- HRTで鍛えられた「数学×実装速度×厳密さ」がスタートアップ創業に直結

### B. ブロックチェーン／DeFi

```
ブロックチェーン = 銀行なしで取引を記録できる分散台帳
スマートコントラクト = 「条件が揃ったら自動実行」するコード契約
DeFi = スマートコントラクトで動く「銀行のいらない金融サービス」
```

- 従来の取引：A→銀行→B（銀行が中間でチェック・承認）
- DeFi：A→コード→B（コードが自動的にチェック・実行）
- Hyperliquidはこれを使って「証券会社なしで先物取引できる市場」を作った
- 2025年Q3時点でDeFiの預け入れ総額は2370億ドル

### C. AI推論（Inference）と半導体（GPU）

```
学習（Training） = AIに大量データを見せて賢くする（教師の仕事）
推論（Inference） = 学習済みAIを実際に使う（生徒が試験を解く）
```

- ChatGPTの返答を生成している処理が「推論」
- 推論にはGPU（グラフィックチップ）が必要
- CPUは「シェフが一人でレシピを順番にこなす」
- GPUは「100人の副料理人が同時並行で作業する」→AI処理に圧倒的有利
- Scale AI（データ）・Cognition（コーディングAI）・Perplexity（検索AI）は全員、この推論チップの上に乗っかっている

## なぜHRTから次世代マフィアが生まれたか

| 共通要素 | 詳細 |
|---------|------|
| **採用基準の高さ** | IOI・IMO・物理オリンピック金メダルレベル。「世界で最も賢い20代」が集結 |
| **実戦環境** | インターン初日から本番と同じインフラ・データ。圧倒的な実践力 |
| **数学×実装の融合** | 「アルゴリズムを数学的に設計し、ミリ秒で実装する」スキルがAI時代に直撃 |
| **クロスポリネーション** | 同期同士で「次は何をやるべきか」を議論。Hyperliquidの創業はScale AIの創業者も絡んでいた |
| **退屈さ** | HRTの仕事に疑問を感じた（"自分が社会に価値を提供しているか？"）→ 起業へのモチベーション |
